## このページの役割
このページは、Mind-Upload の理論指向の公開ページを区別するのに役立つ補助ガイドです。 WBE 101 は序論、Perspective は長い研究ノート、Perspective の理論フレーム セクションは設計原則、Roadmap は依存関係のマップであるため、これらは同じ役割を持ちません。

ここで扱っているのは、ページの役割の違いです。理論の妥当性や検証条件自体は本文の各ページでご確認ください。

## 現在わかっていること
- WBE 101、Perspective、Perspective 内の理論フレーム セクション、およびロードマップはすべて理論的なものですが、それらの役割は異なります。
- WBE 101 は議論の強度を調整するためのエントリ ポイントであり、Perspective は根拠と制限をリストした長いテキストであり、Perspective 内の理論フレーム セクションは設計原則であり、ロードマップは依存関係のマップです。
- 最初にページの役割を分けておくと理論を読み間違えにくくなります。

## まだわかっていないこと
- 最終的にどの理論の組み合わせが十分条件となるかはまだ決まっていません。
- 今後どの理論ページが独立して展開されるかはポイントの蓄積に応じて変わります。

<h2>よくある迷い方</h2>

<h4>間違い</h4>
<ul>
<li><strong>いきなりPerspective:</strong>からスタート 情報量が多いので、まずはWBE 101で議論レベルを準備しておいた方が無難です。 </li>
<li><strong>証明された結論として「理論フレーム」セクションを読んでください:</strong> これは設計原則の要約であり、証明が完了したという宣言ではありません。 </li>
<li><strong>ロードマップを理論テキストとして読む:</strong> これは、理論の背景が凝縮された依存関係マップです。 </li>
<li><strong>FAQ への短い回答で理論的判断を完了します:</strong> 議論が強ければ強いほど、視点と検証に立ち返る必要があります。 </li>
</ul>
