データ

データは目的別に使う

公開データは、マインドアップロードの完成を示すものではありません。L0 の再実行、L1 の同条件比較、L2 の候補仮説分離を練習するための基盤です。

ここでの L0/L1/L2 は、主張のレベルに対応します。L0 は再実行、L1 は同条件比較、L2 は競合仮説を落とす検証です。

使い分け

  • 入門データ: 解析手順と品質管理を学ぶ。
  • 比較データ: 手法間の差と前処理依存性を見る。
  • 仮説分離データ: 同じ結果を生む複数モデルを分ける。
  • 外部検証データ: 別条件で結論が残るかを確認する。

研究優先順位に対応するデータ設計

目的最低限必要な記録不足すると何が起きるか
識別可能性を上げる競合モデル、摂動、保持データ、状態ラベル。同じスコアを別の内部状態が説明しても見逃します。
EEG / BCI デコードを評価するイベント定義、刺激ログ、同期、電極配置、不良チャンネル、別日データ。被験者識別、装置差、事前分布のショートカットを神経証拠と誤読します。
マルチモーダル統合を評価する同時刻同期、同一セッション状態、各モダリティの前処理履歴、欠測ポリシー。共通因子とモダリティ固有因子を混ぜてしまいます。
状態継続を評価する日付、状態注釈、再校正手順、デコーダ固定期間、ドリフト指標。同じ被験者内の性能維持を、同じ内部状態の保持と誤読します。
破壊的構造測定を評価する保存条件、遅延、固定方法、登録範囲、生体内測定との対応点。固定後の構造を生体内の現在状態として扱ってしまいます。

L0 最小ループ

このページの L0 は三つに分けて読みます。この最小ループは実際の作業順、L0 アーティファクトパックは提出物、EEG から L0 へ進む 6 ゲートはスコアを見る前に固定する監査順序です。

  1. 公開データを一つ選ぶ最初は BIDS や NWB など、メタデータと検証ツールがある形式を優先します。
  2. イベント意味と時刻同期を確認する波形があるだけでは、何を比較しているかは固定されません。
  3. ベースラインを再現する論文スコアではなく、同じ分割、同じ前処理、同じ評価を再現します。
  4. 代替説明を一つ落とす被験者識別、セッション識別、装置差、状態ラベルの漏れを最低一つ監査します。
  5. 棄権を記録する判断不能な結果も、次のデータ設計を決める成果として残します。

最初に使う公開データの選び方

旧 Datasets / EEG 101 では、最初のデータ選びを「難しいものを選ぶ競争」ではなく、再実行できる小さな練習板を作る作業として扱っていました。現在のサイトでも同じです。下の候補は例示であり、データセット名だけではなく、タスク、ラベル来歴、分割単位、イベント忠実度、ベンチマークの意味を先に固定します。

やりたいこと候補データ練習できることまだ主張しないこと
前処理と分類の基礎を練習するEEG Motor Movement/Imagery Dataset などの cue-locked EEG。イベントロック、フィルタ、チャンネル処理、同一セッションの分類、単純ベースライン。安定した内部状態復元、日跨ぎ耐久性、ソース完全性。
長時間記録とイベント検出を扱うCHB-MIT などの長時間 EEG。イベント感度、誤報、時間単位の評価、しきい値、除外ログ。AUROC や精度だけで実用アラーム性能が示されたという主張。
状態遷移を扱うSleep-EDF などの睡眠 EEG。状態ラベル、段階ごとの性能、マクロ F1、Cohen's kappa、スコアラー依存性。睡眠ラベルだけで統合や翌日保持が説明できたという主張。
大規模・臨床寄りの難しさを見るTUH EEG などの大規模 EEG。施設差、デバイス差、参照系、ラベル来歴、欠測、外部検証の難しさ。大規模データで高スコアが出たことを、汎用神経デコーダの成立と読むこと。

同じスコアでも、評価ファミリーが違えば意味が変わる

旧ページで繰り返し強調していたのは、スコアの数字よりも「何を独立にしたか」です。同じ 70% でも、同じ日の同じ被験者での 70% と、別日・別被験者・別デバイスでの 70% は、研究判断として別物です。

評価ファミリー何をテストしているか必要な開示避けるべき誤読
セッション内同じ日の同じ取得条件で、対象ラベルを分けられるか。同一録画からの窓漏洩、イベント単位、被験者単位集計。日跨ぎ安定性や運用可能性の証拠とは読まない。
セッション間同じ被験者の別セッションへ、表現やデコーダが残るか。日付、時間帯、状態注釈、固定デコーダ期間、再校正の有無。同じ内部状態が保持された証拠とは読まない。
被験者間別の人へ一般化するか。被験者分割、人口統計、装置・施設の分布、メタデータのみベースライン。個人固有のアップロード条件が読めた証拠とは読まない。
適応 / few-shot少量ラベルや再校正で性能を回復できるか。追加ラベル量、適応時間、推論予算、失敗時の回復負荷。固定デコーダの耐久性とは読まない。
閉ループ(公開データでは参考軸)リアルタイムで状態推定や制御が使えるか。遅延、ジッター、ドロップアウト、安全停止、ユーザー状態。オフライン高スコアと同じ意味では読まない。

L0 アーティファクトパック

旧 Wiki の L0 最小パックは、単なる「データ + コード + スコア」では弱すぎる、という結論でした。L0 はアップロードの証拠ではありませんが、L0 が弱いと、その上の L1/L2 の失敗理由を切り分けられません。

バンドル最低限入れるもの抜けた場合の問題
同一性(Identity)データセット名、バージョン、DOI または永続 URL、取得日、ライセンス、利用したサブセット。同じ名前の別リリースや別サブセットを混ぜます。
可観測性(Observability)BIDS / EEG-BIDS 構造、イベント忠実度、ラベル来歴、チャンネル・電極・参照系、同期ログ。何を観測し、どのラベルを予測したのかが後から追えません。
評価(Evaluation)評価ファミリー、独立ホールドアウト単位、予測対象、メトリックバンドル、ベンチマーク規則、ショートカット検査。同じスコアが別の科学的対象を測っているように見えます。
時間的有効性(Temporal Validity)日跨ぎや適応を扱う場合、状態注釈、固定デコーダ期間、再校正量、遅い内部環境を分けて記録する。同日成功を長期耐久性として過読します。
系統(Lineage)raw と derivative の境界、前処理レシピ、生成元、設定ファイル、環境、ランダムシード。再実行できても、同じ入力・同じ処理だったかが不明になります。
再実行(Replay)実行コマンド、ロックファイルまたはコンテナ、QC レポート、失敗例、主張停止文。成功例だけが残り、L0 をより強い証拠として読みすぎます。

EEG から L0 へ進む 6 ゲート

EEG の最初の実践は、モデルを先に走らせることではありません。旧 EEG to L0 ルートでは、スコアを見る前にベンチマーク対象、時間範囲、イベント意味、系統、停止主張を固定する順序にしていました。

順序ゲートここで固定すること次へ進む条件
1測定上限EEG が直接測るもの、推定に留まるもの、WBE に直結しないもの。頭皮上で混合された集団電位の指標であり、細胞・回路の現在状態の直接観測ではない、と止める。
2ベンチマーク対象データセット、タスク、ターゲット、分割単位、メトリック、公式ルール。短いベンチマークカードとL0 Artifact Packが書ける。
3時間範囲セッション内、同日、日跨ぎ、長期、固定デコーダ、再校正デコーダを分ける。Temporal Validity Card に必要な項目が埋まる。
4観測ログイベント時刻、イベント意味、ラベル来歴、クロックドメイン、遅延・ジッター、不良セグメント。波形、イベント、ラベル、同期を別々に監査できる。
5再実行パックraw ID、derivative ID、実行 ID、QC、ベースライン、失敗レジストリ。第三者が同じ条件で再実行できる。
6停止主張L0 の上限、可観測性の上限、ショートカットの上限、時間的有効性の上限。結果がどこまでで止まるかを明文化する。

公開データを L1 / L2 へ上げる追加ルート

L0 は再実行の土台です。そこから L1 や L2 へ進むには、スコアを上げるだけでは足りません。同じデータから、何がショートカットで、何が候補内部状態の分離に効いたのかを分けます。

段階研究で足すもの前へ進む条件まだ止める主張
L0 から L1 同じ raw ID、同じ分割、同じメトリックで、複数の前処理・特徴量・モデルを比較し、ショートカット対照を同じ表に置く。 ベンチマークカード、固定分割、メタデータのみベースライン、単純モデル、強いモデルを同じ表で比較できる。 最良モデルが真の内部状態を復元した、とはまだ言わない。
L1 から L2 競合仮説を先に書き、保持データ、状態遷移、摂動、負例で候補を落とす。 少なくとも一つの代替説明が、事前に定めた反証条件で落ちる。落ちなかった候補も候補集合として残す。 候補が一つに近づいても、全脳・長期・身体込みのエミュレーションとは数えない。
セッション間へ拡張 固定デコーダ、再校正デコーダ、追加ラベル量、日付、状態注釈、時間帯、睡眠や疲労の proxy を分ける。 性能低下、回復量、再校正負荷、ドリフト指標を一緒に出せる。 同じ被験者で性能が残ったことを、同じ内部状態の連続性とは読まない。
被験者間・施設間へ拡張 被験者 grouped holdout、施設 grouped holdout、装置・参照系・電極配置・サンプリング差の対照を入れる。 被験者識別、施設識別、デバイス識別だけで説明できる性能を差し引ける。 大規模データで高スコアが出たことを、汎用神経デコーダの成立とは扱わない。
マルチモーダルへ拡張 同一セッションの EEG/fMRI/PET/MRSI/行動を、共通因子、分岐因子、欠測、時間カーネルごとに分ける。 Fusion Card と Human Proxy Composition Card が埋まり、単一モダリティとの差分が説明できる。 複数 proxy の相関や予測改善を、潜在状態の一意復元とは言わない。

EEG ベンチマークカードで必ず分けるもの

旧 EEG 101 の重要点は、EEG を過小評価することではなく、EEG の成果を正しい主張レベルへ置くことでした。特に、時間分解能の強さ、空間推定の弱さ、装置・被験者・状態のショートカットを同じカード内で監査します。

欄書くこと止める誤読
測定フレームチャンネル数、電極配置、参照系、サンプリング、フィルタ、インピーダンス、不良チャンネル、同時記録の有無。チャンネル数や高密度を、内部状態の一意復元と混ぜない。
イベント忠実度onset、duration、sample、clock domain、trigger と物理刺激の差、遅延、ジッター、ラベル来歴。events.tsv があるだけで、イベント意味と同期が十分だとは読まない。
評価ファミリーセッション内、セッション間、被験者間、施設間、few-shot、閉ループ参考軸を分ける。同じスコアを、別日の耐久性や別人への一般化と混同しない。
メトリック意味分類なら per-class、睡眠なら macro F1 / kappa / stage 別、発作なら感度・誤報・遅延・時間単位。accuracy や AUROC だけで、実用性能や神経寄与を語らない。
ショートカット対照EOG/EMG/動き、被験者 ID、セッション ID、施設、装置、参照系、窓漏洩、ラベル漏洩。神経信号ではない識別手がかりを、神経デコードの成果として扱わない。
ソース推定の検証クラスsimulation、phantom、頭蓋内刺激、同時 SEEG、術後転帰など、何で検証したかを分ける。ESI や inverse solution を、一般的な独自再構成として読みすぎない。

公開データで最速に進む優先順

最初から「アップロードに一番近そうなデータ」を探すと、主張が大きすぎて失敗理由が見えなくなります。公開データでは、低いレベルから順に、落とせる代替説明を増やします。

  1. Cue-locked EEG でイベントと分割を固めるイベント時刻、ラベル、チャンネル、QC、窓漏洩を監査し、L0 の再実行パックを作ります。
  2. 睡眠や長時間 EEG で状態ラベルと時間評価を扱う状態遷移、rare event、誤報、遅延、scorer 差を扱い、メトリックの意味を固定します。
  3. 大規模臨床 EEG でショートカットを壊す施設、装置、参照系、被験者 ID、ラベル来歴の対照を入れ、L1 の比較が何を測ったかを狭めます。
  4. 同一セッション・マルチモーダルで proxy を分解するEEG だけでなく、行動、fMRI、PET、MRSI などを使う場合は、共通因子と分岐因子を明示します。
  5. 保持データや摂動で候補仮説を落とすここで初めて L2 の候補内部状態分離に近づきます。落ちない候補は失敗ではなく、次の実験設計の入力として残します。
