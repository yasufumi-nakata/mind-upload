用語解説

コネクトーム / connectome
定めた範囲の神経細胞と接続を記述したデータです。細胞・領域・化学／電気シナプスの網羅範囲と、欠損・誤りを別に示します。完全性や機能再現を意味する語ではありません。[1][2]
シミュレーション / simulation
仮定したモデルの振る舞いを計算することです。計算できることと、元の生物の機能に対応することは別に検証します。[3]
エミュレーション / emulation
ここでは、元の系の機能を、指定した条件と時間尺度で対応させることを目指す再現を指します。論文の計算結果を確かめる計算再現とは区別します。[4]
全脳エミュレーション / whole-brain emulation (WBE)
脳全体を対象として、元の個体の機能をモデルで再現する研究目標です。全脳の構造データや限定課題の予測だけで、達成したとは判定しません。[3][4]
システム同定 / system identification
観測と介入に合うモデルの形式やパラメーターを推定することです。観測に合う候補が一つだけとは限りません。[5][6]
逆問題 / inverse problem
観測された結果から、それを生んだ状態やモデルを推定する問題です。観測過程と仮定を明示します。[5][7]
識別可能性 / identifiability
利用できる観測と介入で、異なる候補モデルやパラメーターを区別できる性質です。対象モデル、測定範囲、刺激に依存します。[6]
縮退 / degeneracy
ここでは、異なる回路パラメーターが似た活動を生むことを指します。似た活動への適合だけでは内部機構が一つに定まらない場合があります。[8]
忠実度 / fidelity
事前に選んだ機能、条件、時間尺度について、モデルと元の系がどれだけ対応するかです。細部の多さだけでは決まりません。[4]
閉ループ / closed loop
感覚入力が行動を変え、その行動が次の感覚入力を変える相互作用です。身体・環境・制御器の条件も指定します。[9]
感覚フィードバック / sensory feedback
行動によって変わった身体や環境の情報が、感覚入力として戻ることです。[9]
カルシウムイメージング / calcium imaging
細胞内カルシウムに応じた蛍光信号を記録する方法です。信号は膜電位や全ての発火を直接記録した値ではなく、時間応答とノイズを含む観測過程を通ります。[10]
基準蛍光に対する相対変化 / relative change in fluorescence (ΔF/F)
基準の蛍光信号に対する、蛍光信号の変化の比です。基準の決め方と前処理を示します。膜電位や発火時刻を直接表す量ではありません。[11]
エングラム / engram
記憶の保持・想起に関わる物理的変化や細胞集団を指します。候補を同定することと、個体の記憶をモデルへ復元することは別です。[12]
有芯小胞 / dense-core vesicle
電子密度の高い中心部を持つ分泌小胞です。神経ペプチド等の伝達に関わり、シナプスの接続だけでは捉えにくい情報の候補になります。[13]
漏れ積分発火モデル / leaky integrate-and-fire model (LIF)
入力の積分と漏れをモデル化し、閾値を超えると発火する単純化したニューロンモデルです。全ての細胞内機構を記述するものではありません。[14]
オプティカルフロー推定 / optic flow estimation
画像の時間変化から、画像上の見かけの動きの場を推定する課題です。Lappalainenらのモデルの学習課題を指すときに使います。[15]
電子顕微鏡法 / electron microscopy (EM)
電子を用いて微細構造を撮像する方法です。撮像範囲・分解能と、そこから得られる接続情報を区別して示します。[16]
膨張顕微鏡法 / expansion microscopy (ExM)
試料を物理的に膨張させ、光学撮像で細部を分けやすくする方法です。倍率、標識、変形、読み出せる構造を確認します。[17][16]
膨張ライトシート蛍光顕微鏡法 / expansion light-sheet fluorescence microscopy (ExLSFM)
膨張顕微鏡法とライトシート蛍光撮像を組み合わせる方式です。Collinsらの全脳取得の試算には、未実証の技術の組合せと将来性能の仮定が含まれます。[16]
セグメンテーション / image segmentation
画像を細胞などの対象領域へ分ける処理です。学習用・評価用データを分けるデータ分割とは区別します。[1]
過分割・誤併合 / split and merge errors
一つの細胞を別々に分ける誤りと、別の細胞を一つに結ぶ誤りです。画像再構成の誤りとして扱います。[1]
データ分割 / data split
学習・調整・評価に使うデータを分けることです。時間、セッション、個体の依存関係と予測対象に合わせて分割します。[18]
評価用データ / held-out data
このサイトでは、モデルの学習・調整・選択に使わないデータを指します。独立性は分割方法と予測対象に照らして確認します。[18]
画像再構成 / image reconstruction
このサイトの工程の使い分けでは、撮像データから細胞の形や接続を組み立てる作業を指します。モデルの復元・推定とは区別します。[1]
モデルの復元 / model inference
観測からモデルの状態・パラメーター・規則を推定することです。元の情報を正しく取り戻せたかは、独立の評価で確かめます。[5]
プルーフリーディング / proofreading
コネクトーム再構成では、自動処理の追跡・分割・併合などの誤りを人が確認して修正する作業です。本サイトでこの意味の「校正」を使う場合は、この説明を添えます。[1]
較正 / calibration
ここでは、測定値やデコーダーの出力を、基準データや対象者に合わせて調整することです。再構成誤りの人手修正と区別する表記です。
計算再現 / computational reproduction
ここでは、同じデータとコード・分析手順を用いて、報告された計算結果を確かめることです。生物機能のエミュレーションとは区別します。
独立追試 / independent replication
ここでは、独立に得たデータや独立した実装で結果を確かめることです。どのデータ・実装・担当者が独立かを明示します。
網羅率 / completeness
指定した細胞・領域・接続などを、再構成がどれだけ含むかです。何を分母にした割合かと、不明な部分を明示します。[2]
シナプス数 / synapse count
数えたシナプスの個数です。同じ細胞対に複数のシナプスがあるため、接続した細胞対の数（辺数）とは異なります。[2][15]
シミュレーションベース推論 / simulation-based inference (SBI)
シミュレーションから得たデータを用いて、観測に合うパラメーターなどを推定する方法です。近似事後分布を使う場合も、モデル・事前分布・観測の仮定に依存します。[19]
条件で候補を順に絞る推論法 / filter simulation-based inference (fSBI)
Confavreuxらが、活動や重みの条件を順に適用し、可塑性規則の候補の分布を絞るために用いた方法です。得られる分布が真のベイズ事後分布とは限りません。[20]
近似事後分布 / approximate posterior
モデルと事前分布を仮定し、観測後のパラメーター等の不確実性を近似した確率分布です。集中していても、モデルが正しい保証にはなりません。[19]
被覆確率 / coverage probability
指定した生成条件の下で標本抽出と区間計算を繰り返したとき、区間が真の値を含む確率です。一つの観測済み区間に真値が入る事後確率とは区別します。[21]
同等性マージン / equivalence margin
同等とみなせる差の境界です。本サイトではεと表し、課題上の意味と独立の測定を根拠に、結果を見る前に定める提案です。[22]
許容誤差 / error tolerance
取得や再構成などで、目的上許す誤差の範囲です。どの量と工程の誤差かを指定し、同等性の判定幅とは区別します。
2つの片側検定 / two one-sided tests (TOST)
差が同等性マージンの下側と上側をそれぞれ超えないかを調べる、同等性検定の手順です。通常の差の検定が非有意なだけでは、同等性を示せません。[22]
交換可能性 / exchangeability
帰無仮説の下で、指定したラベルの入替えによって同時分布が変わらない条件です。依存関係や性・段階の違いを無視して個体を入れ替えてよい、という意味ではありません。
置換検定 / permutation test
帰無仮説の下で許されるラベルの入替えから、統計量の比較分布を作る検定です。何を入れ替え、どの依存関係を保つかを決めます。
Holm法 / Holm correction
小さい順に並べたp値へ順次厳しくなくなる基準を当て、多重検定の家族内誤り率を管理する手順です。検定集合を事前に定めます。
検出力 / statistical power
特定の効果とデータ生成条件が真のとき、予定した検定が帰無仮説を棄却する確率です。標本数だけでなく、効果量・ばらつき・検定・補正に依存します。[22]
ノイズシーリング / noise ceiling
反復測定のばらつきから見積もる、指定した予測指標の上限です。測定条件と推定法に依存し、神経機構の正しさを保証しません。[23]
最大到達相関係数 / maximum attainable correlation coefficient (CCmax)
Schoppeらの方法で、試行間の変動から推定する相関係数の上限です。指定した応答と反復測定の条件に対する値です。[23]
正規化相関係数 / normalized correlation coefficient (CCnorm)
Schoppeらの方法で、観測された予測相関を推定上限で正規化した値です。上限の推定誤差や仮定も確認します。[23]
平均絶対誤差 / mean absolute error (MAE)
予測値と測定値の差の絶対値を、評価対象の要素について平均した値です。対象の量、単位、集計方法を揃えて比べます。[11]
期待応答との相関二乗 / squared correlation with the expected response (r²_ER, r^2_ER)
試行ごとの変動を除いた期待応答と、モデル予測の相関二乗を表す量です。真の量とその推定量を区別し、補正推定量や区間の仮定を確認します。[21]
推定値を中心とする信用区間 / estimate-centered credible interval (ECCI)
PospisilとBairが提案したECCIという区間計算法を指します。論文の応答モデルと事前分布等の条件に依存するため、任意の神経データにそのまま適用する手順ではありません。[21]
信号対雑音比 / signal-to-noise ratio (SNR)
信号の大きさとノイズの大きさの比です。何を信号・ノイズとし、分散・振幅などどの量で計算するかを指定します。[21]
識別行列 / identification matrix
本サイトの比較案では、行をモデルの由来個体、列を評価対象個体とし、各組合せの成績を記録する行列です。細胞の対応付けやモデル選択は評価用データから独立に決めます。
時間尺度 / timescale
評価する現象が変化する時間の長さです。瞬間の応答、学習、長期保持などを区別し、観測の時間分解能とも分けて示します。[4]
マイルストーン / milestone
研究計画の中間目標です。本サイトでは、評価可能な成果と達成基準を定めます。予定年に必ず達成するという予測ではありません。
評価時点 / review window
本サイトが研究の進捗と依存関係を見直す時期です。技術が完成すると予測する期日ではありません。
達成基準 / gate criteria
次の研究段階へ進む判断に使う、事前に定めた比較と必要な成果です。各実験の条件と証拠に合わせて判定します。
アルデヒド安定化凍結保存 / aldehyde-stabilized cryopreservation (ASC)
アルデヒド固定と凍結保存を組み合わせる方法です。報告された微細構造の保存と、記憶や機能の保存・復元は別の主張です。[24]
Brain Modeling ToolKit (BMTK)
複数の詳細度で脳回路モデルを構築・シミュレーションするためのソフトウェア群です。ツールの存在自体は、作成したモデルの妥当性を保証しません。[25]
Open Science Framework (OSF)
研究計画の事前登録や資料共有に利用できるプラットフォームの名称です。登録だけで計画の妥当性が保証されるわけではありません。
プレプリント / preprint
査読後の正式出版より前に公開された原稿です。閲覧した版、公開日、査読・出版状況を確認します。

内部状態・学習則と観測モデル

以下は本サイトが説明のために用いる概念的な表記です。単一の既存論文の式や、完成した脳モデルを転載したものではありません。

x(t+Δt) = F(x(t), u(t); θ(t))
θ(t+Δt) = G_ψ(θ(t), x(t), u(t))
y_k = H_φ(x_{≤t_k}) + η_k

xは膜電位や適応などの速い状態、uは刺激・報酬などの入力、θは接続強度や伝達特性です。Fは応答、Gは学習や可塑性による変化を表し、ψは学習則のパラメーターです。何を状態とパラメーターに分けるかは時間尺度に依存します。点ニューロンか多区画モデルかというモデルの形そのものも検証の対象です。膜電流の定量モデルと、入出力からの神経系同定が基礎になります。[26][5]

yは実測信号、Hは内部状態から計測・前処理後の信号への観測モデル、φはその較正パラメーター、ηは観測誤差です。過去の状態への依存は、カルシウム応答の遅れや時間的な広がりなどを表せます。測定した基準蛍光に対する相対変化（ΔF/F）とモデル内の膜電位は、そのまま同じ量として比べません。ΔF/Fを直接出力する予測器は、その観測信号の空間で比較できます。[11]

コネクトームに加えて、受容体や神経修飾によって応答が変わり得ます。必要な詳細度は、省略した要素を戻したときに、独立した評価条件で予測が改善するかで調べます。[13][4] 測定信号との比較は検証手順、Gをデータから選ぶ方法は学習則の同定で具体化します。

計測法ごとの情報と限界

計測得られる主な情報単独では不足する点
電子顕微鏡（EM）微細形態とシナプス接続固定後の像から生前の活動履歴を直接読めるわけではありません。
膨張顕微鏡法（ExM）・分子標識形態と標識した分子の位置標識の抜け、歪み、対応付け、撮像量を評価する必要があります。
電気生理・カルシウム画像時間変化、刺激応答、集団活動全細胞の全状態を同時に観測できるとは限りません。
摂動と行動計測介入への応答と入出力関係同じ行動を別の内部機構で実現できる可能性が残ります。
グリアの標識・活動・選択的介入細胞型、学習関連集団、神経活動への調節形態だけで機能状態や記憶内容が分かるわけではありません。必要な状態は課題ごとに検証します。
ペプチド・受容体と誘発応答シナプス外伝達を含む有効な信号伝播遺伝子発現は放出量や受容体状態の直接測定ではなく、誘発応答には間接経路も含まれます。

MICrONSは、同じ個体の構造と活動を対応付ける具体例です。LICONNは、組織を約16倍に拡大し、光学像から密な再構成と分子標識の併用を可能にしました。撮像した最大の組織体積は約100万 µm³（0.001 mm³）で、全脳規模の実証ではありません。分子標識には保持されにくい抗体・条件もあるため、目的とする分子ごとの確認が必要です。[10][17]

測定方式は、解像度、体積、取得速度、欠損、費用、再構成誤差を合わせて比べます。撮像時間の試算を、保存から機能検証までの総所要時間と読み替えないことも重要です。[16]

配線の外側にある伝達：Randiら（2023）は、動かない状態の線虫C. elegansで単一ニューロンを光刺激しました。頭部の23,433ニューロン対で、刺激から応答への信号伝播を調べています。有芯小胞放出に関わるunc-31変異体との比較などから、解剖学的接続だけでは捉えられないシナプス外伝達の寄与を示しました。測るのは直接・間接経路を含む応答であり、単シナプスの接続数ではありません。特定モデルとの不一致を、配線に基づくモデルすべての失敗とは一般化できません。[27]

グリアや分子情報を全て測ることが必須だと結論したわけではありません。省略・追加モデルを同じ未使用条件で比較し、必要な測定を選ぶ方針です。省略要素の検証手順をご覧ください。[28]

データからモデルへの逆問題

異なるパラメーターの回路から、似た活動が生じることがあります。この縮退は、観測に合う答えが一つとは限らないという問題です。[8]

Hanらは正解の分かる人工視覚モデルを用い、活動予測の得点だけでは正しいモデル構造を選べない条件を示しました。一方、観測するユニットの範囲や刺激を変えると、識別しやすさも変わります。結論は「同定は不可能」ではなく、候補を区別できる観測を設計する必要があるということです。[6]

研究上は、想定する介入の範囲で同じ機能を示すモデルの集合を、暫定的な到達点にできます。その際は、どの条件で同じと判定したかを明記し、未測定の条件まで同じだと外挿しません。接続、活動、課題、介入という異なる制約を組み合わせて候補を絞ります。[15][6]

不確実性を含めて推定する：ここで扱うシミュレーションベース推論（SBI）は、観測に合うパラメーターを一組に絞らず、確率分布として推定します。この近似事後分布をp(θ | y, M)と書きます。θはパラメーター、yは観測、Mは仮定したモデルです。推定は指定した事前分布にも依存します。Gonçalvesらは神経動態モデルで、同様の出力を生む複数の解とパラメーター間の補償関係を推定しました。ただし、分布はモデル・事前分布・観測特徴・ノイズ仮定に依存します。これ自体は、任意の介入での同等性や全脳の一意な復元の保証ではありません。[19]

本サイトの提案では、事後分布から予測を作り、未使用の刺激・介入で候補間の違いを調べます。正解が分かる人工モデルでの被覆確率や、事前分布を変えた場合の安定性も検査します。具体的な評価項目はM1に示します。

理論が支える範囲：NETTは、学習した正則化を用いる逆問題について、一定の連続性や強制性などの仮定の下で、解の存在・安定性・収束を解析しています。数値例は光音響画像の再構成です。ここでは神経回路の同定を直接扱う結果ではなく、一般的な逆問題の理論例として位置付けます。この種の保証は、制約付き推定を設計する手掛かりになりますが、脳の正しい状態を一意に復元できる保証へそのまま移せません。[7]

観測モデルHとその較正φも、推定の前提として固定または不確実性を評価します。活動が合わない原因を、回路の状態・接続と、計測の遅れ・混合・ノイズに分けます。学習中のデータを使う場合は、初期の接続強度θと更新則Gの違いも調べます。学習則の同定へ進みます。

記憶に関わる構造と復元の検証

Uytiepoら（2025）は、マウスの恐怖学習時に活動した細胞を標識し、1週間後の海馬の局所シナプス構造を調べました。主な電子顕微鏡比較は学習群3匹・対照群2匹で、複数の棘へ接続する終末などに差が見られました。一方、同時に標識された細胞同士が優先的につながるという単純な結果ではありません。学習に伴う構造差を捉えた研究であり、任意の記憶内容を解読した研究ではありません。[12]

記憶の構造的基盤を尋ねた研究者調査でも、必要な情報の尺度や実現可能性には見解の幅がありました。調査中の「静的構造」は個々の生体分子まで含む広い定義で、理想的な保存の成功を仮定しています。回答の割合を、復元成功率や保存された記憶の割合として読むことはできません。[29]

次の研究では、同じ個体の学習と測定を対応付けます。評価には、モデル調整に使わなかった想起課題を残します。そこで、記憶の保持と忘却、再学習、介入後の変化を調べます。モデルへ評価課題の正解を追加学習させると、元の記憶から復元できたかを判定できなくなるため、学習と評価を分離します。

神経細胞以外の寄与：マウス海馬では、学習時に標識したアストロサイト集団の再活性化とNFIAの選択的欠失により、恐怖記憶の想起行動への寄与が示されました。神経エングラムを人工活性化すると欠失群の想起行動が回復する結果もあります。アストロサイトだけに記憶が保存されることや、全脳再現に全グリアの全状態が必須であることを示した研究ではありません。[28]

保存方法の成果と機能復元の条件

アルデヒド安定化凍結保存（ASC）は、固定した組織の微細構造を保つ方法です。2015年の研究では、最終条件のウサギ8例と良好に処理できたブタ1例などを顕微鏡で評価しました。神経突起やシナプスを追跡できる像は得られましたが、生理機能や学習済み記憶の復元は評価していません。[24]

次に必要なのは、保存前後で何が変わるかを測り、その損失が機能予測をどの程度変えるかまで追う実験です。微細構造の保持、必要な状態の保持、情報の読み出し、機能の検証は、それぞれ独立した到達点です。[30]

学習則の同定と未知条件での検証

学び続けるモデルには、現在の重みだけでなく、その変わり方Gが必要です。学習中の神経活動・行動の経過に、候補となる規則を合わせる研究があります。初期の重みθ、規則のパラメーターψ、観測の較正φは分けて扱います。

  • 人工回路からの回復：Mehtaらは、回路構造を一致させた人工モデルで既知の規則を回復し、ノイズや観測細胞の不足も検査しました。生物では18匹のハエの選択行動へ適用し、重み減衰を含む候補を評価しています。後の時点への予測が悪い個体もあり、生物の唯一のGを同定した結果ではありません。[31]
  • 候補を一つに絞り過ぎない：Confavreuxらは、活動と重みの条件を満たす規則の族をスパイキングモデルで探索しました。似た活動を異なる規則が生み、filter simulation-based inference（fSBI）の分布は必ずしも真のベイズ事後分布ではありません。[20]
  • 生物の介入で制約する：Higeらのハエ実験では、匂いとドーパミン神経の活性化による抑圧が、刺激の順序とキノコ体の区画に依存しました。一つの共通規則を全区画へ当てはめる前に、こうした違いを検査できます。[32]

本サイトの実験案：

  1. 正解Gの分かる人工回路を観測モデルHへ通し、ノイズ・欠測・構造誤りを変えます。観測信号の予測、重みの推移、規則の回復を別々に採点します。
  2. 次にキノコ体などの構造・介入の情報を制約とし、学習中の神経・行動の経過で複数のGを推定します。回路構造、初期重み、観測変換、規則族の仮定を残します。
  3. モデル選択に使わない報酬条件の変更、消去、逆転学習、保持期間で予測を比べます。評価中はGのパラメーターを固定し、そのGによる重みの更新を許します。評価の答えでGを再調整しません。
  4. 未知条件への予測が再現すれば、同じ個体の保持・忘却・再学習を長期に比較し、身体とつなぐルート3へ進みます。候補が区別できなければ、予測が分かれる測定・介入を追加します。全候補が外れれば、構造・初期重み・観測モデル・規則族を見直します。

この経路は研究提案です。人工回路での規則回復、ハエの限定課題への適合、全脳の長期学習、既得記憶の復元は、別々に検証します。
