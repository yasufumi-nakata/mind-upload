## 今回の選定理由

- サイトはすでに `inverse problem`、`validation class`、`solver-disagreement` をかなり丁寧に分離できておりました。
- しかし 2026-03-22 時点でも、`そもそも何が頭皮まで見えるのか` という upstream の制約が、公開ページではなお圧縮されすぎていました。
- この弱点が残ると、読者は `高密度化`、`より良い inverse solver`、`intracranial validation` を見ただけで、一般的 internal-state recovery へ滑りやすくなります。
- 技術・自然科学の観点では、ここを補強しない限り `可視性`、`逆問題`、`直接検証` の 3 層が混線したままです。

## 根拠付き批判

### 1. 逆問題より前に、場形成そのものの可視性壁があります

- 問題:
  - 旧 `eeg_101.md` は `volume conduction` を low-pass filter と説明していましたが、`source extent`、`orientation`、`cortical folding`、`cancellation` が何を頭皮上に残し、何を落とすかを十分には分けていませんでした。
- 根拠:
  - Ahlfors et al. (2010, *Brain Topography*) は realistic boundary model で source orientation 依存性を定量化し、最低感度/最高感度比の中央値が `MEG 0.06`、`EEG 0.63` と大きく異なることを示しました。
  - Ahlfors et al. (2010, *Human Brain Mapping*) は extended / distributed source による cancellation を示し、源が存在しても表面信号が保たれるとは限らないことを示しました。
  - Goldenholz et al. (2009) は cortical SNR map を用い、source extent と anatomy によって EEG/MEG の優劣が変わること、mesial temporal では `3 cm^2` と `8 cm^2` source patch で約 `10 dB` の差が出うることを示しました。
- 批判:
  - したがって `見えない = 存在しない` ではなく、同時に `source-localized = もともと見えていた hidden state が一意に回収された` でもありません。
  - この upstream 壁を public rule にしないまま inverse discussion だけを強めるのは不十分です。

### 2. EEG/MEG の感度差はアルゴリズム名ではなく geometry と tissue でも変わります

- 問題:
  - 旧サイトは conductivity 不確実性と head model を扱っていましたが、`CSF を落とすだけで EEG SNR を過大評価しうる` という visibility-side correction が前面化されていませんでした。
- 根拠:
  - Piastra et al. (2021) は six-compartment anisotropic FEM で、CSF を無視すると EEG SNR を過大評価すること、cortical / subcortical sensitivity が depth と orientation に強く依存することを示しました。
- 批判:
  - したがって `high-density EEG + MRI` だけを見て `deep observability がかなり解けた` と読むのは不適切です。
  - head model の粒度は downstream inverse の問題であるだけでなく、upstream visibility estimate 自体に食い込みます。

### 3. 直接検証は重要ですが、validated の意味は依然として条件付きです

- 問題:
  - 旧サイトは `validation class` を分けていましたが、field-formation の議論が弱いままだと `intracranially validated` が general deep-state observability に誤読される余地が残ります。
- 根拠:
  - Mikulan et al. (2020) は intracerebral stimulation ground truth benchmark を提供しましたが、刺激は非生理的であり sampling は clustered です。
  - Unnwongse et al. (2023) は 3,619 stimulation site、11 patients で mean localization error `10.3-26 mm` を報告しました。
  - Hao et al. (2025) は simultaneous HD-EEG/SEEG で ictal/interictal ESI を比較し、`14.07 ± 4.62 mm` vs `17.38 ± 4.16 mm` を報告しました。
- 批判:
  - これらは重要な前進ですが、`field-formation wall` と `inverse/model wall` を越えたことの証明ではありません。
  - よって `validated` は `条件付き localization benchmark を通過した` までであり、`general internal-state recovery` ではありません。

- 健常者・同一被験者・非病理 spontaneous activity に対する large-scale simultaneous scalp/intracranial benchmark
  - 担当者: 同時計測系研究者 / dataset maintainer / benchmark 設計者
