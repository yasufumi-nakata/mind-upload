# マインドアップロード — 検証可能な研究ポートフォリオ

マインドアップロード（脳のデジタル化と意識の転送）を「できる／できない」の印象論では
なく、**検証可能な研究課題へ分解する公開ノート**です。固定からエミュレーションまでの
実装パイプライン、未解決ギャップ（P1–P8）、検証カード、プロジェクトの来歴を一枚に
まとめています。

公開先: <https://mind-upload.com/>

## 中心命題

> 最重要は「可観測性（observability）」ではなく「識別可能性（identifiability）」である。
> 測定量を増やしても、同じ観測を説明する競合内部状態が複数残るなら、アップロード条件は
> 閉じない。最速ルートは「もっと測る」ことではなく、**摂動・保持データ・外部検証で候補
> 内部状態を減らす**ことにある。

## 構成

このサイトは外部依存・ビルド工程の無いプレーンな静的サイトです。

| パス | 役割 |
|---|---|
| `index.html` | サイト本体（単一ページ）。概要・過去研究・実装パイプライン・主張レベル・未解決ギャップ・維持状態・検証カード・根拠・来歴の各セクション |
| `assets/css/main.css` | 全体のスタイル（モダンダークテーマ） |
| `assets/og-cover.png` | SNS共有用のカバー画像（1200×630） |
| `favicon.svg` | ファビコン |
| `404.html` | カスタム404ページ |
| `robots.txt` / `sitemap.xml` | クローラ向けメタ情報 |
| `RESEARCH-DIGEST.md` | 研究まとめ＋未解決ギャップ集（読み物としての出典まとめ） |
| `CNAME` | GitHub Pages のカスタムドメイン設定（`mind-upload.com`） |

## ローカルでの確認

ビルドは不要です。リポジトリ直下で静的サーバを立てて開きます。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

`file://` で直接 `index.html` を開いても表示できますが、`/favicon.svg` や `404.html`
など絶対パス参照の確認にはローカルサーバの利用を推奨します。

## デプロイ

GitHub Pages がリポジトリのデフォルトブランチ（`main`）のルートから直接配信します。
`main` へ push すると自動的に反映されます。独自ドメインは `CNAME` で設定済みです。

## ライセンス・出典

研究内容の出典は `RESEARCH-DIGEST.md` にまとめています。本文中の文献は日付ではなく
「どの主張をどこまで支えるか」で整理しています。
