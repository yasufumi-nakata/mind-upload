<section class="section" id="fields">
<h2 class="section-title">各ページの共通欄</h2>
<div class="key-points">
<h4>Common Fields</h4>
<ul>
<li><strong>観測量：</strong>何を測れば前進かを見る欄です。横断整理は <a href="{{ '/wiki/observables-and-proxies.html' | relative_url }}">観測量と代理指標</a> を参照してください。</li>
<li><strong>最小実験設計：</strong>最小限どんな比較を行えば良いかを示します。共通レシピは <a href="{{ '/wiki/minimum-experiment-designs.html' | relative_url }}">最小実験設計</a> にまとめています。</li>
<li><strong>主要反証条件：</strong>何が起きたらその仮説を退けるかを明示します。考え方の整理は <a href="{{ '/wiki/falsification-and-stop-rules.html' | relative_url }}">反証条件と停止規則</a> を参照してください。</li>
<li><strong>停止規則：</strong>どの条件で主張を弱めるか、公開を止めるかを示します。典型的な崩れ方は <a href="{{ '/wiki/failure-modes.html' | relative_url }}">失敗様式カタログ</a> で一覧化しています。</li>
<li><strong>典型反論：</strong>その問いに対して最も強く返ってくる批判を短く整理します。主張強度の読み方は <a href="{{ '/wiki/claim-ladder.html' | relative_url }}">クレーム階段</a> も参照してください。</li>
<li><strong>誤読されやすい点：</strong>読者が「解けた」と勘違いしやすい地点を先回りで外します。関連する事故例は <a href="{{ '/wiki/failure-modes.html' | relative_url }}">失敗様式カタログ</a> にあります。</li>
<li><strong>必要データセット：</strong>最低限どの種類のデータやログが必要かを示します。共有・標準化の入口は <a href="{{ '/datasets.html' | relative_url }}">データ&ベンチ</a> と <a href="{{ '/wiki/bids-and-eeg-bids.html' | relative_url }}">BIDS / EEG-BIDS</a> です。</li>
<li><strong>最小ベースライン：</strong>まず何に勝たないと主張が立たないかを示します。考え方は <a href="{{ '/wiki/benchmark-pitfalls.html' | relative_url }}">ベンチマークの罠</a> を参照してください。</li>
<li><strong>主要文献クラスター：</strong>その問いに効く文献群を、計測・モデル・意識・倫理などの塊で示します。入口は <a href="{{ '/wiki/literature-and-evidence-map.html' | relative_url }}">文献導線と証拠地図</a> です。</li>
<li><strong>必要評価指標：</strong>観測量の中でも、合否や比較のために最低限固定すべき指標を示します。補助線は <a href="{{ '/wiki/observables-and-proxies.html' | relative_url }}">観測量と代理指標</a> と <a href="{{ '/verification.html' | relative_url }}">Verification</a> を参照してください。</li>
<li><strong>外部依存タスク：</strong>AI が今回のセッションで直接実行できない事項を、担当・前提条件・完了条件つきで分離して書きます。</li>
<li><strong>反対仮説：</strong>その結果を別の弱い説明で言い換えられないかを明示します。過大解釈を防ぐ欄です。</li>
<li><strong>最小公開物：</strong>そのページの主張を最低限どこまで公開すれば比較可能かを示します。公開運用の補助線は <a href="{{ '/wiki/reproducibility-basics.html' | relative_url }}">再現性とベンチ</a> を参照してください。</li>
<li><strong>失敗時の巻き戻し条件：</strong>何が起きたら、より弱い主張へ下げるかを示します。主張の段階は <a href="{{ '/wiki/claim-ladder.html' | relative_url }}">クレーム階段</a> と対応します。</li>
<li><strong>初学者向け一問一答：</strong>そのページで最初につまずきやすい点を、短い Q/A で解きます。</li>
<li><strong>用語の入口：</strong>読む前に押さえるべき用語集や基礎ページへの入口です。まず <a href="{{ '/glossary.html' | relative_url }}">用語集</a> を確認できます。</li>
<li><strong>比較表：</strong>そのページで最低限区別すべき概念を、左と右で並べて整理します。</li>
<li><strong>研究者向けチェックリスト：</strong>実験登録、比較、公開の最低条件を短く確認する欄です。</li>
<li><strong>想定レビューコメント集：</strong>そのページで査読者やレビュー担当からまず返ってきやすい指摘を、先回りで整理する欄です。</li>
<li><strong>査読で突かれやすい弱点：</strong>主張が崩れやすい設計上の穴を短く明示する欄です。典型的な崩れ方は <a href="{{ '/wiki/failure-modes.html' | relative_url }}">失敗様式カタログ</a> も参照してください。</li>
<li><strong>図版候補キャプション：</strong>そのページを図で説明するなら何を描くべきかを、最小単位で固定する欄です。発表資料や論文草案の再利用を意識しています。</li>
<li><strong>最小数式：</strong>そのページで最低限固定したい関係式や判定式です。厳密理論ではなく、測定契約を曖昧にしないための最小記法として置きます。</li>
<li><strong>評価プロトコル擬似コード：</strong>実験や評価をどの順番で行うかを、再利用しやすい形で短く固定する欄です。</li>
<li><strong>典型反例シナリオ：</strong>主張が成り立たない具体例を先に置き、どの失敗が本質的かを見分ける欄です。</li>
<li><strong>実験ログの雛形：</strong>最低限どの列をログとして残すべきかを、表形式で固定する欄です。追試可能性と失敗解析の両方に使います。</li>
<li><strong>判定フローチャート：</strong>そのページの主張を、どの条件で進め、どの条件で弱めるかを順序立てて示す欄です。停止条件の運用版として読めます。</li>
<li><strong>最小アブレーション表：</strong>最低限外すべき要素を固定し、主張が何に依存しているかを確認する欄です。</li>
<li><strong>想定 rebuttal 断片：</strong>査読コメントや反論に対して、どの証拠を返すかを短く固定する欄です。論文の rebuttal や質疑応答の下書きに使えます。</li>
<li><strong>図版制作メモ：</strong>図を作る際の軸、色、凡例、注記の固定ルールを短く残す欄です。図版ごとの解釈ぶれを防ぎます。</li>
<li><strong>査読で要求されやすい追加実験：</strong>そのページで、次に何を追加すると主張が一段強くなるかを短く示す欄です。</li>
<li><strong>脚注向け注意書き：</strong>本文に入れると流れを壊すが、誤読防止に必要な但し書きを短く残す欄です。</li>
<li><strong>発表スライド1枚要約：</strong>その問いを 1 枚で説明するなら何を残すかを、問い・方法・落とし穴の最小構成で示す欄です。</li>
<li><strong>否定結果の見せ方：</strong>失敗や崩壊条件を、どの粒度でどう公開するかを固定する欄です。成功例だけに寄らない証跡づくりを意図しています。</li>
<li><strong>用語の誤用例：</strong>そのページで誤って同一視されやすい語や、言い過ぎになりやすい表現を先回りで外す欄です。</li>
<li><strong>最小比較実験の失敗パターン集：</strong>最低限の比較設計で、どこを外すと結論が壊れやすいかを短く示す欄です。</li>
<li><strong>ベンチ設計テンプレート：</strong>比較対象、主要指標、最低対照、失敗条件を 1 表で固定する欄です。</li>
<li><strong>口頭発表Q&amp;A想定集：</strong>発表時によく返ってくる質問と、その場で返す最低限の回答を短く整理する欄です。</li>
<li><strong>主張の強さを下げる言い換え集：</strong>言い過ぎを避けつつ、何が分かったかを残すための safer phrasing 集です。</li>
<li><strong>採択されにくい危険な表現集：</strong>過大主張や誤読を招きやすく、査読や発表で不利になりやすい表現を先に外す欄です。</li>
<li><strong>図表の最小凡例セット：</strong>軸名、閾値、比較群など、図表で落とすと誤解が生じやすい凡例項目を固定する欄です。</li>
<li><strong>関連Uページとの往復問題集：</strong>別の U ページと行き来しながら理解を深めるための短い問い集です。</li>
<li><strong>初学者が最初に読む3段階ルート：</strong>概念の前提から当該 U ページへ入るための最短 3 ステップです。入口の順番を固定して、読み飛ばしによる誤解を減らします。</li>
<li><strong>研究者が最初に潰すべき交絡3点：</strong>最初に切り分けないと結論全体を汚しやすい交絡を、優先度順に短く示す欄です。</li>
<li><strong>このページだけで誤解しやすい論点：</strong>他ページを読まずに当該ページだけを見たときに生じやすい短絡や誤読を先回りで潰す欄です。</li>
<li><strong>次に書くべき姉妹ページ案：</strong>現ページでは扱い切れないが、次に独立ページ化すると理解と運用が進むテーマ候補です。</li>
<li><strong>そのページを1文で言うと：</strong>ページ全体の論点を 1 文に圧縮し、何を問うページなのかを最短で掴む欄です。</li>
<li><strong>最低限の前提知識チェック3問：</strong>読む前に最低限分かっているべき用語や区別を、短い Q&amp;A で自己点検する欄です。</li>
<li><strong>ありがちな研究設計の空振り例：</strong>その論点でよくある設計ミスを先に見せ、無駄な評価や誤主張を避ける欄です。</li>
<li><strong>本文へ戻る逆リンク強化：</strong>未解決問題カタログ、関連概念ページ、本体ページへ戻る逆リンクを固定する欄です。深掘り後に全体文脈へ戻りやすくします。</li>
<li><strong>最小図表セット：</strong>その論点を最低限伝えるのに必要な図表だけを固定する欄です。主張より先に、何を 1 枚目・2 枚目・表 1 に置くかを決めます。</li>
<li><strong>読み終えた後の3段階理解確認：</strong>読了後に、初歩・中級・応用の 3 段階でどこまで理解できたかを自己点検する欄です。</li>
<li><strong>査読で通しやすい書き順テンプレート：</strong>定義、比較、失敗条件、控えめな結論の順に並べるための最小構成です。論文草案や発表原稿の骨格に使えます。</li>
<li><strong>本体ページ側からの逆参照補強：</strong>WBE 101 や Verification などの本体ページから、どの文脈でその U ページへ戻すべきかを固定する欄です。</li>
<li><strong>30秒説明版：</strong>そのページの論点を会話や会議で即答できる長さに圧縮した欄です。初学者向けの入口にも、研究者向けの口頭要約にも使えます。</li>
<li><strong>図表キャプションの最短版：</strong>図1・図2・表1にそのまま貼れる最小キャプションを先に固定する欄です。図の役割を短文でぶらさずに保てます。</li>
<li><strong>初学者が誤解しやすい比喩の修正：</strong>分かりやすさのための比喩が、かえって誤解を生む箇所を修正する欄です。講義や説明資料での事故を減らします。</li>
<li><strong>会議で使う確認質問5個：</strong>研究会や打ち合わせで、そのページの論点が本当に共有できているかを短時間で点検する質問集です。</li>
<li><strong>失敗した研究会発表の典型例：</strong>その論点を雑に話したときに、どこで伝達事故が起きるかを先回りで示す欄です。発表準備で削るべき弱い構成が分かります。</li>
<li><strong>採択されやすい図の並べ順：</strong>図や表をどの順に出すと、前提・比較・失敗条件が伝わりやすいかを固定する欄です。スライドと論文の両方に流用できます。</li>
<li><strong>学生向け課題化テンプレート：</strong>その U ページを演習や輪読課題へ落とすときの、課題・提出物・採点観点の最小セットです。</li>
<li><strong>研究計画書の一段落版：</strong>研究計画書や申請書に貼れる長さで、そのページの問い、方法、意義を一段落に圧縮した欄です。</li>
<li><strong>査読者タイプ別の刺さる説明：</strong>同じ内容でも、計測寄り、理論寄り、再現性寄りなど査読者の関心軸ごとに何を前面に出すべきかを示す欄です。</li>
<li><strong>共同著者間で揉めやすい論点の整理：</strong>主張強度、図の順番、失敗例の扱いなど、執筆段階で割れやすい論点を先回りで言語化する欄です。</li>
<li><strong>口頭試問向けの想定問答：</strong>質疑応答で高確率に問われる点と、その場で返す最小限の回答を短く固定する欄です。</li>
<li><strong>最終スライドの締め文候補：</strong>発表の最後で言い過ぎずに論点を閉じるための短い締め文を複数用意する欄です。</li>
<li><strong>図1だけで話す版：</strong>時間が極端に短い発表や会議で、そのページの核を図1一枚でどう伝えるかを固定する欄です。</li>
