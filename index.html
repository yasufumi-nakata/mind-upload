中心命題

最重要は「可観測性」ではなく
「識別可能性」だ。

The one-line thesis

測定量を増やしても、同じ観測を説明する競合内部状態が複数残るなら、アップロード条件は閉じない。

だから最速ルートは「もっと測る」ことではなく、摂動・保持データ・外部検証で候補内部状態を減らすことにある。

① 再現基盤

公開データ・イベント同期・QC・ベースラインを整え、第三者が同じ結果を再現できる状態にする。

② 識別可能性

測定値を増やすだけでなく、同じ観測を説明する競合内部状態を、摂動と保持データで落とす。

③ 状態継続

同じ脳・被験者・デコーダでも、時間・固定・再校正をまたいで何が同じ状態として残るかを監査する。

過去の研究のまとめ

古典的な夢から、測定と実装の問題へ。

論点の起源は 1990 年代の Strout Mind Uploading Home Page。当時の問いを、現在の検証条件へ読み替える。 全脳エミュレーション(WBE)は哲学から測定・実装の問題へ移ったが、配線図だけでは現在状態・可塑性・代謝・グリア・血管・免疫・記憶固定を閉じられないことも明確になった。

古典的論点当時の問い現在の読み替え
物理主義心は物理的な脳過程から生じるか作業仮定としては必要。ただし復元対象・十分条件は決まらない
ミクロトーム / 破壊的スキャン薄切り画像から脳を再構築できるか構造足場は強まるが、固定・保存・染色・時間遅延・現在状態の喪失が残る
ナノ置換 / Moravec 型連続置換徐々に置き換えれば同一性は保てるか連続性は直感的に強いが、各段階で機能・状態・身体ループが保たれたかは未検証
非破壊アップロードMRI 等で生きたまま読み出せるか解像度・逆問題・proxy 性・共有ドライバー・モデル負荷が上限になる
人格同一性と複製コピーは本人か。複数コピーは許すか技術的復元 / 心理的連続性 / 法的同一性 / 社会的同意は別問題
人工現実 / 人工身体アップロード後の環境・身体はどうあるべきか身体・環境は周辺でなく、内受容・報酬・睡眠・恒常性・社会関係を通じ状態を変える

主張の強さは5段階。混同してはいけない。

相関

二つの量が一緒に変わる。
→ 交絡・共通原因の確認が要る。

予測

ある信号から別の状態を当てられる。
→ 別条件・別個体・別装置での汎化が要る。

識別

候補状態を区別できる。
→ 競合モデルが残らないことの検証が要る。

因果

介入で結果が変わる。
→ 摂動・反事実・保持された検証条件が要る。

再現

別の人が同じ手順で確認できる。
→ データ・コード・環境・評価の公開が要る。

読み方

デコード・予測の高スコアを、識別・因果・再現へ勝手に昇格させない。

完成技術とその実施

実装パイプライン：実際にどう行うのか

マインドアップロードは単一の発明ではなく、固定 → 走らせるまでの依存パイプラインです。 各段を「何をするか／どう行うか／現在地／実施の壁」に分けて検討する。前段が弱いまま後段へ進むと「見かけの進歩」になる。

まず、戦略は三つに分岐する

破壊的スキャン

固定 → 連続切片 → 電子顕微鏡。構造は最高解像度だが、現在の動的状態は失われ、生体には不可逆。
適用: 段 01–02 を厚く。

非破壊測定

生体のまま多モダリティで読み出す。可逆だが、解像度・逆問題・proxy が上限。
適用: 段 03–04 を厚く。

漸進的置換 (Moravec 型)

ニューロンを少しずつ人工素子へ置換。連続性は直感的に強いが、各段階の機能保存を逐次検証する必要。
適用: 段 05–08 を反復。

どのルートでも、下流（再構成 → エミュレーション → 検証）は共通。違うのは前半の取得方法と、何を失うかだ。

確立 — 実証済みの手法がある 部分的 — 一部スケール／条件で実証 未確立 — 原理的・スケール的に未達

生体保存・固定Preservation & fixation

構造○ / 状態×
やること

脳の超微細構造を、分解が始まる前に物理的に安定化して固定する。

どう行うか

血管経由でアルデヒドを灌流固定 → アルデヒド安定化クライオ保存(ASC)や M22 ガラス化、または樹脂包埋。死後〜固定の遅延（虚血）を最小化。

現在地

ASC がブタ脳でシナプスレベルの構造保存を実証（McIntyre & Fahy／大型哺乳類脳保存賞 2018）。

実施の壁

固定の瞬間に電気・代謝・放出確率・イオン環境など「現在の動的状態」が失われる。ヒト全脳で虚血前に均一灌流するのが難しい。

→ P2 維持状態Destructive-Structure Route Card

構造取得（コネクトミクス）Volume EM connectomics

小〜中規模○ / ヒト全脳×
やること

ニューロンとシナプスの全結線図（コネクトーム）を取得する。

どう行うか

マルチビーム電顕・Hot-Knife 切片化で 30–50nm 連続切片を撮像 → Flood-Filling Networks でAI自動セグメンテーション、SOFIMA で整列 → シナプス検出・配線再構成。

現在地

ハエ全脳 FlyWire（Dorkenwald 2024）、マウス視覚皮質 1mm³ MICrONS（2025）、ヒト側頭葉 1mm³ H01（Shapson-Coe 2024）。

実施の壁

ヒト全脳（~1,500cm³）は現行解像度でゼタバイト級・推定数十年。形態だけからシナプスの符号・強度は完全には読めない。

→ P4 構造制約モデル→ P7 公開データ

分子・維持状態の取得Molecular / synaptic-state capture

部分的
やること

配線図に現れない分子状態（受容体・伝達物質・可塑性・代謝）を測る。

どう行うか

免疫EM・アレイトモグラフィ・拡張顕微鏡(ExM)・Ex-EM で構造と分子を共登録、MERFISH/BARseq 等の空間トランスクリプトミクス。

現在地

全マウス脳の空間トランスクリプトーム細胞型アトラス（Yao 2023）、EM からの神経伝達物質予測。

実施の壁

固定標本に「現在の」放出確率・興奮性・代謝・睡眠状態は残らない。同一シナプスで分子と超微細構造を非破壊に共登録できない。

→ P2 維持状態維持状態バジェット

機能・動態の測定In-vivo functional / dynamics

動物○ / ヒト△
やること

回路の動的パラメータと活動を、できれば生体で測る。

どう行うか

in vivo 2光子 Ca²⁺/電圧イメージング、高密度電気生理（Neuropixels 2.0）、同一脳の機能→構造パイプライン。ヒトは非侵襲 EEG/fMRI/PET/MRSI/OPM-MEG/機能的超音波(fUS)。

現在地

MICrONS は同一マウスで機能記録→コネクトーム。ヒト発話 BCI（Willett 2023; Metzger 2023）。

実施の壁

ヒトでは頭蓋越しに単一細胞・ミリ秒の活動を非侵襲記録できない（物理限界）。観測から内部状態は一意化しない。

→ P1 識別可能性→ P3 マルチモーダル

再構成・パラメータ推論Reconstruction & inference

縮退で停滞
やること

測定データから、走らせられる回路モデルのパラメータを決める。

どう行うか

シミュレーションベース推論(SBI)、コネクトーム制約の深層機構モデル、逆問題/ベイズ推定。曖昧性クラスを宣言し、摂動・保持データで候補を落とす。

現在地

コネクトーム重みから直接、ハエ視覚・航法系の機構シミュレーション（Lappalainen 2024; Beiran & Litwin-Kumar 2025）。

実施の壁

パラメータ縮退 — 同じ基底発火を生む複数のイオンチャネル/神経調節状態が残り、構造だけからは一意推論できない（Prinz 2004）。

→ P1 / P4識別可能性カード

エミュレーション基盤Emulation substrate

スケール未達
やること

再構成モデルを計算基盤で実時間に走らせる。

どう行うか

大規模生物物理シミュレーション（NEURON, Arbor, NEST）、ニューロモルフィック HW（SpiNNaker 2, Intel Loihi 2, BrainScaleS-2）、GPU/HPC。

現在地

Intel Hala Point が 11.5 億ニューロン規模の実時間研究システムを実現（2024）。線虫 OpenWorm 部分。

実施の壁

ヒトは ~860 億ニューロン・~10¹⁴–10¹⁵ シナプス。スパイクのインターコネクト遅延・メモリ帯域・消費電力・生物学的タイミング忠実度。

→ L3 閉ループ実装

身体・環境の接続Embodiment

部分的
やること

感覚・運動・内受容・恒常性の閉ループを供給し、脳モデルを「身体」につなぐ。

どう行うか

仮想身体/環境（MuJoCo, Isaac Sim）、双方向 BCI、内受容・報酬・睡眠・恒常性ループのモデル化。

現在地

脳-脊髄インターフェースで自然な運動・感覚を回復（Lorach 2023）、双方向 BCI が進展。

実施の壁

どの身体ループを保存し、どれを置換するか。低遅延の感覚フィードバックがないと脳状態が急速に発散する。遅い内部環境の供給。

→ P8 身体・環境Body / Environment Boundary Card

検証（同一性）Validation of identity

未確立
やること

再構成された心が「元と同じ」と言える条件を、操作的に確かめる。

どう行うか

行動的同一性テスト、摂動応答の一致、反事実検証、段階的アブレーション、保持データでの候補棄却。主張は L0–L5 で止める。

現在地

動物の局所回路では摂動応答比較が可能。全脳・人格レベルの検証法は未確立。

実施の壁

経験的反証不能性 — 完璧に振る舞うコピー／哲学的ゾンビと、主観的経験の真の連続とを区別する物理測定が存在しない。

→ L4 / L5仮説検証

倫理・運用ゲートEthics & operations

未整備
やること

技術的成功を、同意・権利・安全へ接続する。

どう行うか

同意プロトコル、コピー数・分岐・更新・停止権の規約、安全停止、悪用防止、監査権限。

現在地

制度設計は技術に先行して未整備。

実施の壁

技術的復元 ≠ 法的・社会的同一性。実現前から制度条件を技術条件と分けて設計する必要。

必要条件→ P8
popular coverage が最も誇張する点: 「コネクトームを取得した = 脳が走る」ではない。構造マップ単体には、機能エミュレーションに要る神経調節・イオン・分子の動的状態が欠けている（縮退ギャップ）。段 02 の成功は段 05–06 の成功を意味しない。

主張のレベル

クレームラダー L0 → L5

進捗は「印象」ではなく、どの証拠なら主張を一段上げられるかで読む。 上位レベルの言葉を急ぐより、下位レベルを再現可能に厚くするほうが、現時点では研究速度を上げる。

L0

公開データ・イベント・同期・QC・ベースラインが再現できる。

内部状態を識別できたとは言えない。

L1

複数手法を同じ条件で比較できる。

最良スコアが真の状態復元とは限らない。

L2

摂動や保持データで競合仮説を落とせる。

全脳・長期・身体込みの十分性はまだ別。

L3

閉ループ実装で特定機能を安定して再現できる。

人格同一性や全体的な意識の主張には届かない。

L4

同一個体内で状態継続と再校正負荷を説明できる。

コピー問題・社会的同意・長期倫理は残る。

L5

技術・検証・運用・同意・停止条件が揃う。

哲学的同一性の立場まで自動解決はしない。

どこができていないのか

未解決ギャップ：研究優先順位 P1–P8

順位は流行や日付ではなく、未解決の大きさ・波及効果・検証可能性で決める。まず「候補内部状態を減らす研究」から始める。

まず、まだわかっていないコア4問

Q1

どの粒度の構造と状態が、個人らしさ・記憶の再現に必要十分か。

Q2

生きた人間から、必要な状態変数をどこまで非破壊に測れるか。

Q3

同じ出力を生む複数の内部モデルを、どの実験で分離できるか。

Q4

長期の安定性・学習・睡眠・身体性をどう検証するか。

三つの壁 — ここを通らないと「見かけの進歩」で止まる

測定粒度の壁

過読: 高密度・高解像なら必要状態をほぼ測れた。

確認: 直接観測 / proxy / 推定 / 未測定を分け、時間窓と数量タイプを明示。

識別性の壁

過読: 予測精度が上がったから内部状態も一意に決まった。

確認: 候補モデル空間・曖昧性クラス・保持データ・摂動・棄権規則を事前固定。

介入検証の壁

過読: オフラインデコードが良いから因果的再実装に近い。

確認: 摂動応答・閉ループ・状態遷移・日跨ぎ安定性・別条件検証を要求。

P1–P8：未解決の中身と「次の実験」

P1

識別可能性を上げる摂動設計

測定量が増えても、同じ観測を説明する内部状態が複数残る。

次: 競合モデルを列挙し、状態遷移・持続励起・介入・保持データでどれが落ちるか事前登録。

P2

維持状態のカード化

コネクトームではシナプス効率・興奮性・代謝・ECM/PNN・睡眠・グリア・血管・免疫を固定できない。

次: 各状態に直接観測量・代理量・時間窓・摂動可能性・棄権境界を分けてカード化。

P3

同一個体マルチモーダルの分解

EEG/fMRI/PET/MRSI/行動が同一対象から取れても共通因子と固有因子が混ざる。

次: 同一セッションで共通因子・分岐因子・装置固有誤差・状態ラベルのずれを分離。

P4

コネクトーム制約モデルの残差監査

構造は足場だが、動的パラメータ・現在のシナプス状態を一意に決めない。

次: 構造に活動記録・摂動・外部タスクを追加し、残る候補集合を明示。

P5

状態継続ブリッジの検証

同じ脳・被験者・デコーダでも、日跨ぎ・固定後の状態同一性は別問題。

次: 運ばれる対象・許容誤差・失敗規則・再調整負荷・救済ルートを明示。

P6

デコードとエミュレーションの分離

言語・運動を高精度予測できても、内部状態を生成的に再実装したことにならない。

次: 予測スコア・神経寄与・言語事前分布・閉ループ性能・長期安定性を別々に評価。

P7

公開データで L0→L2 を厚くする

大きな主張の前提となる低レベル再現性がまだ薄い。

次: BIDS/NWB・イベントログ・同期・QC・保持データ・ベースライン・ショートカット対照・棄権規則を一体公開。

P8

身体・環境・内受容ループの境界

脳単体の再現では感覚・運動・報酬・睡眠・恒常性の閉ループを保証できない。

次: どの身体ループを保存/置換し、どの遅い内部環境を合わせるか実験ごとに開示。

維持状態 (P2 の中身)

コネクトームに「黙って含めてはいけない」遅い状態

配線図だけで固定できない状態ファミリー。どれが個別機能に必要十分かは未解決。

固有興奮性 / AIS / イオンチャネル シナプス効率 / 放出確率 / 短期・長期可塑性 ECM / PNN / 局所プロテオスタシス 神経調節 (DA / NA / ACh / 5-HT / 神経ペプチド) 転写 / クロマチン / RNA編集 / リン酸化 代謝 / ミトコンドリア / ATP / 熱状態 ミエリン / 希突起膠細胞 (伝導タイミング) グリア基質 / アストロサイト 血管 / BBB / 免疫 / クリアランス 睡眠 / リプレイ / 概日 / 発火率設定点
共通の過読警告: proxy が多いこと ≠ 対象状態が一意に復元できること。一つの代謝指標や血流補正で「支持状態全体を測れた」と読まない。

検証カード

ギャップを潰す道具：12 枚のカード

各カードの役割は「成功宣言」ではなく、どこまでしか言えないか（主張上限）を先に固定すること。未測定状態・モデル負荷・レジーム差・棄権条件を空欄にしない。

可観測性予算

測定変数を増やす研究。直接観測 / proxy / 推定 / 未測定を分ける。

識別可能性カード

逆問題・モデルフィット・デコード。競合モデル・対称性・再パラメータ化・保持データ。

Fusion Card

EEG/fMRI/PET/MRSI の統合。共通因子・固有因子・融合後の残候補集合。

Human Proxy Composition

生きた人間の複数 proxy 合成。各役割・取得負担・外部校正・最強単一行からの増分。

State-Continuity Bridge

同一被験者/脳/日跨ぎ/固定後の橋渡し。運ばれる対象・証人・許容誤差・救済ルート。

Destructive-Structure Route

固定後 EM・破壊的超微細構造測定。保存法・遅延・登録範囲・失われる状態。

Temporal Validity

長期安定性・固定デコーダ・睡眠。時間窓・状態注釈・再校正・ドリフト上限。

維持状態バジェット

コネクトームに含められない遅い状態。状態ファミリー別の観測・proxy・摂動・棄権。

根拠マップ

文献は日付でなく「支える主張」で読む

新しさだけでは根拠の強さは決まらない。どの主張を、どこまで支えるか／何をまだ閉じないかを同じ行で読む。

証拠クラス代表例強くなる主張まだ閉じないもの
全脳/大規模コネクトームDorkenwald+ (2024), MICrONS (2025)構造足場・局所回路・同一脳の構造機能対応現在のシナプス効率・放出状態・代謝・全状態の同時捕捉
コネクトーム制約モデルLappalainen+ (2024), Beiran & Litwin-Kumar (2025)構造が活動予測をどこまで改善するか構造だけで動力学が一意に決まったという主張
可観測性 / 識別可能性Villaverde (2019), Prinz+ (2004), Rasero+ (2024)測れる・区別できる・一意に決まるを分ける必要性観測量が多ければ内部状態が自動的に一意になるという主張
同一個体マルチモーダルVafaii+ (2024), Chen+ (2025)共通パターンと固有パターンを同時に見られる複数モダリティを足せば一つの真の潜在状態に届くという主張
状態継続 / 時間ドリフトGallego+ (2020), Karpowicz+ (2025), Wilson+ (2025)潜在多様体・デコーダをドリフト下で安定化できる可能性安定性能が内部状態の同一性を保証するという主張
破壊的構造測定の保存問題Lu+ (2023)固定・保存・染色が超微細構造に与える影響の監査必要性固定後構造が生体内の現在状態をそのまま残すという主張
データ標準と再現性BIDS, NWB, OpenNeuro第三者が同じデータを検証できる条件標準形式に置いただけで仮説分離・同一性が解けるという主張
