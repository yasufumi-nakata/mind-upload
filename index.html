中心命題

最重要は「可観測性」ではなく
「識別可能性」だ。

The one-line thesis

測定量を増やしても、同じ観測を説明する競合内部状態が複数残るなら、アップロード条件は閉じない。

だから最速ルートは「もっと測る」ことではなく、摂動・保持データ・外部検証で候補内部状態を減らすことにある。

① 再現基盤

公開データ・イベント同期・QC・ベースラインを整え、第三者が同じ結果を再現できる状態にする。

② 識別可能性

測定値を増やすだけでなく、同じ観測を説明する競合内部状態を、摂動と保持データで落とす。

③ 状態継続

同じ脳・被験者・デコーダでも、時間・固定・再校正をまたいで何が同じ状態として残るかを監査する。

過去の研究のまとめ

古典的な夢から、測定と実装の問題へ。

論点の起源は 1990 年代の Strout Mind Uploading Home Page。当時の問いを、現在の検証条件へ読み替える。 全脳エミュレーション(WBE)は哲学から測定・実装の問題へ移ったが、配線図だけでは現在状態・可塑性・代謝・グリア・血管・免疫・記憶固定を閉じられないことも明確になった。

古典的論点当時の問い現在の読み替え
物理主義心は物理的な脳過程から生じるか作業仮定としては必要。ただし復元対象・十分条件は決まらない
ミクロトーム / 破壊的スキャン薄切り画像から脳を再構築できるか構造足場は強まるが、固定・保存・染色・時間遅延・現在状態の喪失が残る
ナノ置換 / Moravec 型連続置換徐々に置き換えれば同一性は保てるか連続性は直感的に強いが、各段階で機能・状態・身体ループが保たれたかは未検証
非破壊アップロードMRI 等で生きたまま読み出せるか解像度・逆問題・proxy 性・共有ドライバー・モデル負荷が上限になる
人格同一性と複製コピーは本人か。複数コピーは許すか技術的復元 / 心理的連続性 / 法的同一性 / 社会的同意は別問題
人工現実 / 人工身体アップロード後の環境・身体はどうあるべきか身体・環境は周辺でなく、内受容・報酬・睡眠・恒常性・社会関係を通じ状態を変える

主張の強さは5段階。混同してはいけない。

相関

二つの量が一緒に変わる。
→ 交絡・共通原因の確認が要る。

予測

ある信号から別の状態を当てられる。
→ 別条件・別個体・別装置での汎化が要る。

識別

候補状態を区別できる。
→ 競合モデルが残らないことの検証が要る。

因果

介入で結果が変わる。
→ 摂動・反事実・保持された検証条件が要る。

再現

別の人が同じ手順で確認できる。
→ データ・コード・環境・評価の公開が要る。

読み方

デコード・予測の高スコアを、識別・因果・再現へ勝手に昇格させない。

主張のレベル

クレームラダー L0 → L5

進捗は「印象」ではなく、どの証拠なら主張を一段上げられるかで読む。 上位レベルの言葉を急ぐより、下位レベルを再現可能に厚くするほうが、現時点では研究速度を上げる。

L0

公開データ・イベント・同期・QC・ベースラインが再現できる。

内部状態を識別できたとは言えない。

L1

複数手法を同じ条件で比較できる。

最良スコアが真の状態復元とは限らない。

L2

摂動や保持データで競合仮説を落とせる。

全脳・長期・身体込みの十分性はまだ別。

L3

閉ループ実装で特定機能を安定して再現できる。

人格同一性や全体的な意識の主張には届かない。

L4

同一個体内で状態継続と再校正負荷を説明できる。

コピー問題・社会的同意・長期倫理は残る。

L5

技術・検証・運用・同意・停止条件が揃う。

哲学的同一性の立場まで自動解決はしない。

どこができていないのか

未解決ギャップ：研究優先順位 P1–P8

順位は流行や日付ではなく、未解決の大きさ・波及効果・検証可能性で決める。まず「候補内部状態を減らす研究」から始める。

まず、まだわかっていないコア4問

Q1

どの粒度の構造と状態が、個人らしさ・記憶の再現に必要十分か。

Q2

生きた人間から、必要な状態変数をどこまで非破壊に測れるか。

Q3

同じ出力を生む複数の内部モデルを、どの実験で分離できるか。

Q4

長期の安定性・学習・睡眠・身体性をどう検証するか。

三つの壁 — ここを通らないと「見かけの進歩」で止まる

測定粒度の壁

過読: 高密度・高解像なら必要状態をほぼ測れた。

確認: 直接観測 / proxy / 推定 / 未測定を分け、時間窓と数量タイプを明示。

識別性の壁

過読: 予測精度が上がったから内部状態も一意に決まった。

確認: 候補モデル空間・曖昧性クラス・保持データ・摂動・棄権規則を事前固定。

介入検証の壁

過読: オフラインデコードが良いから因果的再実装に近い。

確認: 摂動応答・閉ループ・状態遷移・日跨ぎ安定性・別条件検証を要求。

P1–P8：未解決の中身と「次の実験」

P1

識別可能性を上げる摂動設計

測定量が増えても、同じ観測を説明する内部状態が複数残る。

次: 競合モデルを列挙し、状態遷移・持続励起・介入・保持データでどれが落ちるか事前登録。

P2

維持状態のカード化

コネクトームではシナプス効率・興奮性・代謝・ECM/PNN・睡眠・グリア・血管・免疫を固定できない。

次: 各状態に直接観測量・代理量・時間窓・摂動可能性・棄権境界を分けてカード化。

P3

同一個体マルチモーダルの分解

EEG/fMRI/PET/MRSI/行動が同一対象から取れても共通因子と固有因子が混ざる。

次: 同一セッションで共通因子・分岐因子・装置固有誤差・状態ラベルのずれを分離。

P4

コネクトーム制約モデルの残差監査

構造は足場だが、動的パラメータ・現在のシナプス状態を一意に決めない。

次: 構造に活動記録・摂動・外部タスクを追加し、残る候補集合を明示。

P5

状態継続ブリッジの検証

同じ脳・被験者・デコーダでも、日跨ぎ・固定後の状態同一性は別問題。

次: 運ばれる対象・許容誤差・失敗規則・再調整負荷・救済ルートを明示。

P6

デコードとエミュレーションの分離

言語・運動を高精度予測できても、内部状態を生成的に再実装したことにならない。

次: 予測スコア・神経寄与・言語事前分布・閉ループ性能・長期安定性を別々に評価。

P7

公開データで L0→L2 を厚くする

大きな主張の前提となる低レベル再現性がまだ薄い。

次: BIDS/NWB・イベントログ・同期・QC・保持データ・ベースライン・ショートカット対照・棄権規則を一体公開。

P8

身体・環境・内受容ループの境界

脳単体の再現では感覚・運動・報酬・睡眠・恒常性の閉ループを保証できない。

次: どの身体ループを保存/置換し、どの遅い内部環境を合わせるか実験ごとに開示。

維持状態 (P2 の中身)

コネクトームに「黙って含めてはいけない」遅い状態

配線図だけで固定できない状態ファミリー。どれが個別機能に必要十分かは未解決。

固有興奮性 / AIS / イオンチャネル シナプス効率 / 放出確率 / 短期・長期可塑性 ECM / PNN / 局所プロテオスタシス 神経調節 (DA / NA / ACh / 5-HT / 神経ペプチド) 転写 / クロマチン / RNA編集 / リン酸化 代謝 / ミトコンドリア / ATP / 熱状態 ミエリン / 希突起膠細胞 (伝導タイミング) グリア基質 / アストロサイト 血管 / BBB / 免疫 / クリアランス 睡眠 / リプレイ / 概日 / 発火率設定点
共通の過読警告: proxy が多いこと ≠ 対象状態が一意に復元できること。一つの代謝指標や血流補正で「支持状態全体を測れた」と読まない。

検証カード

ギャップを潰す道具：12 枚のカード

各カードの役割は「成功宣言」ではなく、どこまでしか言えないか（主張上限）を先に固定すること。未測定状態・モデル負荷・レジーム差・棄権条件を空欄にしない。

可観測性予算

測定変数を増やす研究。直接観測 / proxy / 推定 / 未測定を分ける。

識別可能性カード

逆問題・モデルフィット・デコード。競合モデル・対称性・再パラメータ化・保持データ。

Fusion Card

EEG/fMRI/PET/MRSI の統合。共通因子・固有因子・融合後の残候補集合。

Human Proxy Composition

生きた人間の複数 proxy 合成。各役割・取得負担・外部校正・最強単一行からの増分。

State-Continuity Bridge

同一被験者/脳/日跨ぎ/固定後の橋渡し。運ばれる対象・証人・許容誤差・救済ルート。

Destructive-Structure Route

固定後 EM・破壊的超微細構造測定。保存法・遅延・登録範囲・失われる状態。

Temporal Validity

長期安定性・固定デコーダ・睡眠。時間窓・状態注釈・再校正・ドリフト上限。

維持状態バジェット

コネクトームに含められない遅い状態。状態ファミリー別の観測・proxy・摂動・棄権。

Neural Contribution

言語/音声/運動/治療 BCI のデコード。タスク制約・事前分布・脳なし対照・閉ループ。

Calibration / Abstention

不確実性が高い結果・閉ループ・予測集合。区間・被覆率・棄権閾値・フォールバック。

L0 Artifact Pack

公開データでの再解析・ベンチマーク開始。データ同一性・イベント忠実度・分割・系統。

Body / Environment Boundary

閉ループ・身体置換・環境相互作用。保存入力・置換出力・内受容・報酬・睡眠の境界。

明日から最速で進めるなら

対象機能を一つ選ぶ

記憶・運動・言語・覚醒など、まず狭く。

競合する内部状態説明を3つ以上書く

同じ出力を別機構で説明する候補を先に出す。

観測量ではなく分離実験を選ぶ

どの測定/摂動が競合候補を最も落とすか。

棄権条件を公開する

候補集合が重なるなら「成功」でなく「未識別」として止める。

公開データの小さな再現ループから

L0 再解析 → L1 同条件ベンチ → L2 候補仮説分離。

根拠マップ

文献は日付でなく「支える主張」で読む

新しさだけでは根拠の強さは決まらない。どの主張を、どこまで支えるか／何をまだ閉じないかを同じ行で読む。

証拠クラス代表例強くなる主張まだ閉じないもの
全脳/大規模コネクトームDorkenwald+ (2024), MICrONS (2025)構造足場・局所回路・同一脳の構造機能対応現在のシナプス効率・放出状態・代謝・全状態の同時捕捉
コネクトーム制約モデルLappalainen+ (2024), Beiran & Litwin-Kumar (2025)構造が活動予測をどこまで改善するか構造だけで動力学が一意に決まったという主張
可観測性 / 識別可能性Villaverde (2019), Prinz+ (2004), Rasero+ (2024)測れる・区別できる・一意に決まるを分ける必要性観測量が多ければ内部状態が自動的に一意になるという主張
同一個体マルチモーダルVafaii+ (2024), Chen+ (2025)共通パターンと固有パターンを同時に見られる複数モダリティを足せば一つの真の潜在状態に届くという主張
状態継続 / 時間ドリフトGallego+ (2020), Karpowicz+ (2025), Wilson+ (2025)潜在多様体・デコーダをドリフト下で安定化できる可能性安定性能が内部状態の同一性を保証するという主張
破壊的構造測定の保存問題Lu+ (2023)固定・保存・染色が超微細構造に与える影響の監査必要性固定後構造が生体内の現在状態をそのまま残すという主張
データ標準と再現性BIDS, NWB, OpenNeuro第三者が同じデータを検証できる条件標準形式に置いただけで仮説分離・同一性が解けるという主張
