Abstract / 要旨

要旨

全脳エミュレーション（WBE）とは、ある脳の構造と状態を十分な解像度で計測し、 その情報処理を計算基盤上で再現することで「心」を非生物的な基板へ移す構想である。 本レビューは、Sandberg と Bostrom が2008年に提示したロードマップ1の枠組みを土台に、 以後の約20年で世界の研究がどこまで到達したかを整理し、2050年の完成へ向けた発展のストーリーを描く。

結論を先取りすれば——構造の取得は線虫からハエ全脳、ヒト皮質1mm³まで実証が進み89、 計測と読み出しはNeuropixelsや発話BCIで臨床到達点に達した713。 一方で パラメータの一意な再構成（縮退問題）5、 生体からの非破壊全脳計測、そして 同一性の検証 が依然として原理的な壁として残る。 2050年完成は「自動的に訪れる未来」ではなく、これらの壁を順に越えた場合に成立する 条件付きのシナリオ である。

1. Introduction / 序論

「心を写す」とは、何を写すことか。

マインドアップロードの中核仮説は 計算主義（substrate-independence）—— 心が脳という特定の物質ではなく、脳が実行する 情報処理の構造 に宿るならば、 その処理を別の基板で十分忠実に再現できれば心もまた再現される、という立場である。 この仮説のもとで WBE は「スキャン＆エミュレート」という工学問題に翻訳される1。

歴史的な出発点は二つある。ひとつは1952年の Hodgkin–Huxley モデル3—— ニューロンの発火を微分方程式で定量再現できることを示し、「脳は計算で書ける」という確信を与えた。 もうひとつは1986年の 線虫 C. elegans の全配線図2—— 302個のニューロンの全結線を顕微鏡で取り切り、「脳は地図にできる」ことを示した。 この 動態の方程式化 と 構造の地図化 の合流点に、WBE という構想が立っている。

本レビューの読み筋: 進歩は「できる／できない」の印象ではなく、依存関係で読む。 構造を取得できても（地図）、それを走らせる動的状態が欠ければ脳は動かない。 各要素技術が どの実証段階にあり、2050へ向けて何が残っているか を分けて辿る。

2. Roadmap / 全体像

完成までを4つの発展フェーズで描く。

世界の研究の趨勢を外挿すると、2050年までの道のりは大きく4期に分けられる。 各期は前期の成果を前提に積み上がる。

〜2025 · 基盤確立

地図と計測の時代

小動物の全脳コネクトーム、ヒト皮質1mm³、高密度記録と臨床BCIが出揃う。「測れる・写せる」が実証された期。

2025–2035 · 統合

マウス全脳への挑戦

哺乳類スケールの構造＋機能の統合データ、分子状態の併記、縮退を抑える構造制約モデルが主戦場になる。

2035–2045 · 動かす

機能エミュレーション

哺乳類脳の領域〜全脳エミュレーションが身体ループ付きで走り、行動レベルで検証される段階。

2045–2050 · 個人化

ヒト個体の再現

特定個人の脳を保存・取得し、記憶と人格を伴う個人化エミュレーションと、その同一性検証へ到達するシナリオ。

3. Enabling Technologies / 要素技術

8つの要素技術：現状と2050への軌跡。

各技術について、いま世界の研究が到達している水準（現状）と、2050に向けて埋めるべき距離（軌跡）を併記する。

3.1

脳保存・構造固定部分実証

分解が始まる前に脳の超微細構造を物理的に安定化する。すべての破壊的取得ルートの出発点。

現状

アルデヒド安定化＋低温保存（ASC）が、ブタ・ウサギ脳でシナプス解像度の超微細構造を全脳にわたり保つことを実証し、Brain Preservation 賞を受賞6。

2050への軌跡

保存が守るのは構造であって動的状態ではない。ヒト全脳での再現性・室温長期保存・取得との接続性が課題。倫理的合意のもとでの手続き標準化が要る。

3.2

コネクトミクス（構造取得）小動物○ / ヒト全脳×

電子顕微鏡でニューロンとシナプスの全結線図を取得する。脳の「配線地図」づくり。

現状

線虫（1986）2からショウジョウバエ 成虫全脳（FlyWire, 約14万ニューロン・5千万シナプス, 2024）910、ヒト皮質1mm³のペタボクセル再構成（H01, 2024）8、マウス視覚野の機能＋構造統合（MICrONS, 2025）11まで到達。

2050への軌跡

ヒト全脳は皮質1mm³の約100万倍。撮像スループット・自動再構成・保管の桁違いのスケーリングが必要。マウス全脳（〜2030年代）が中間目標。

3.3

分子・シナプス状態部分的

配線図に現れない分子状態——受容体・伝達物質の種類・シナプス強度・可塑性・代謝——を読み出す。

現状

アレイトモグラフィや空間トランスクリプトミクスで、シナプスのタンパク質組成や全脳の細胞型地図が取得可能に。EMから一部のシナプス強度の指標が読める。

2050への軌跡

「配線図＝脳が走る」ではない。EM画像から機能的なシナプス重みや神経調節状態へ写像する手法が未確立で、エミュレーション忠実度の律速になりうる。

3.4

神経動態の計測とBCI臨床到達

回路の動的パラメータと活動を、できれば生体で測る。基準となる「正解の振る舞い」を供給する。

現状

Neuropixelsが数千点同時記録を標準化（2017）7。麻痺患者から手書き・発話を高速デコードする皮質内BCI（2021–2023）121314、脳–脊髄ブリッジによる随意歩行の回復15。

2050への軌跡

頭蓋を越えた非侵襲計測には物理限界がある。デコード精度の向上は「内部状態が一意に決まった」ことを意味しない（次項）。全脳・長期・身体込みの同時計測が遠い。

3.5

再構成・パラメータ推論縮退で停滞

計測データから、実際に走らせられる回路モデルのパラメータを一意に決める。WBEの逆問題の核心。

現状

Hodgkin–Huxley型の精密モデルは確立3。Blue Brainは生物学的制約からラットの皮質微小回路を再構成・シミュレートした4。構造制約を使った同定が前進。

2050への軌跡

縮退問題——大きく異なるパラメータ群が同一の活動を生む5。同じ観測から複数の内部状態が残る限り、忠実な再構成は閉じない。摂動・保持データ・外部検証で候補を絞る方法論が最大の難所。

3.6

エミュレーション基盤スケール途上

再構成したモデルを計算基盤で（できれば実時間で）走らせる。シミュレータとニューロモルフィック・ハードウェア。

現状

SpiNNaker16やIntel Loihi17などニューロモルフィック計算機が大規模スパイキングネットを省電力で実行。スパコン上の数十億ニューロン級シミュレーションも実現。

2050への軌跡

ヒト脳は約860億ニューロン・100兆シナプス。実時間・低電力での全脳エミュレーションには、現行から数桁のスケーリングと新アーキテクチャが必要。ムーアの法則の鈍化が逆風。

3.7

身体性・環境部分的

感覚・運動・内受容・恒常性の閉ループを供給し、脳モデルを「身体」につなぐ。脳は孤立では正常に動かない。

現状

BCIによる外部効果器の制御、脳–脊髄ブリッジによる閉ループ運動回復15、仮想アバター制御14など、感覚運動ループの一部は実装段階。

2050への軌跡

内受容・ホルモン・恒常性まで含む全身ループの忠実な供給は未開拓。身体入力が欠けると、エミュレートされた心の長期安定性が保証されない。

3.8

同一性・意識・検証未確立

再構成された心が「元と同じ」「意識を持つ」と言える条件を、操作的に確かめられるか。

現状

意識の理論（統合情報理論18、グローバル・ワークスペース19）の対立を実験で検証する敵対的協働が進行20。だが決着には至っていない。

2050への軌跡

完璧な振る舞いの再現と 主観的連続性 を分ける物理測定は存在しない。コピー問題（元が残ったまま複製が走る）、社会的同意、停止条件など、技術では閉じない論点が残る。

4. Milestones / マイルストーン

到達点と、2050へ向けた予測マイルストーン。

実線（〜2025）は世界の研究で 実証済み の到達点。点線（2025〜）は趨勢からの 予測シナリオ であり、確約ではない。

1952

Hodgkin–Huxley モデル3

ニューロン発火を微分方程式で定量再現。「脳は計算で書ける」基礎。

1986

C. elegans 全配線図2

302ニューロンの全結線を完成。「脳は地図にできる」最初の証明。

2008

WBEロードマップ1

スキャン＆エミュレートの要件と段階を体系化した出発点の文書。

2015

皮質微小回路の再構成4 / ASC受賞6

生物学的制約からの回路シミュレーションと、シナプス解像度の脳保存が実証。

2021–2024

ヒト皮質1mm³8 / ハエ全脳9 / 発話BCI13

構造取得とリアルタイム読み出しが、それぞれ新しいスケールに到達。

~2030s（予測）

マウス全脳コネクトーム＋機能統合

哺乳類スケールの構造・機能・分子の統合データセット。縮退を抑える構造制約推論が成熟。

~2040s（予測）

哺乳類脳の機能エミュレーション

身体ループ付きで行動レベルの再現・検証。ニューロモルフィック基盤が実時間スケールへ。

~2050（予測）

個人化ヒトエミュレーション＋同一性検証

特定個人の保存・取得・再構成と、記憶・人格を伴うエミュレーション、その操作的検証へ到達するシナリオ。

5. Open Challenges / 残る壁

2050が「条件付き」である理由。

外挿だけでは越えられない、原理的・社会的な3つの壁。ここが解けない限り、完成シナリオは前倒しできない。

① 識別可能性の壁。 計測を増やしても、同じ観測を説明する内部状態が複数残るなら再構成は一意に閉じない5。最速ルートは「もっと測る」ことではなく「候補状態を減らす」摂動・検証の方法論である。
② 非破壊・スケールの壁。 生きたヒトから必要な状態変数を頭蓋越しに測る物理限界、そしてヒト全脳の構造取得・計算に要する数桁のスケーリング。破壊的取得を前提にするなら、保存と倫理の問題に直結する。
③ 同一性・倫理の壁。 完璧な振る舞いの再現と主観的連続性を分ける測定は存在しない。コピー問題、本人同意、社会的地位、停止条件——技術の成功だけでは決して閉じない論点が最後に残る。

6. Conclusion / 結論

2050は約束ではなく、依存関係の関数である。

過去20年で、世界の研究は 「測れる」「写せる」 を疑いの余地なく実証した—— 小動物の全脳配線図、ヒト皮質のナノスケール再構成、臨床で動くBCI。 これらは2008年のロードマップ1が「初期段階」と位置づけた地点を、現実が追い越したことを意味する。

だが完成を決めるのは、最も進んだ技術ではなく 最も遅れた依存項 である。 構造取得がいかに速くても、縮退を断つ再構成、全脳スケールの計算、そして同一性の検証が揃わなければパイプラインは閉じない。 したがって2050年完成は、これら律速段階を順に越えた場合に成立する 条件付きシナリオ として読むのが正確だ。 本レビューが示したのは到達予言ではなく、どの壁を越えれば、その未来が手前に近づくか という地図である。
