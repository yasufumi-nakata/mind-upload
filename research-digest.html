0. 一文サマリ

マインドアップロードを「できる／できない」の印象論ではなく、検証可能な研究ポートフォリオへ分解するのがこのサイトの目的。中心命題は一貫して次の一点です。

  • いま最重要の課題は「可観測性（observability）」ではなく「識別可能性（identifiability）」である。
  • 測定量を増やしても、同じ観測を説明する競合内部状態が複数残るなら、アップロード条件は閉じない。
  • だから最速ルートは「もっと測る」ことではなく、摂動・保持データ・外部検証で候補内部状態を減らすことにある。

1. 過去の研究のまとめ

1.1 古典的系譜（1990年代〜）— Strout の Mind Uploading Home Page

論点の起源は Joseph J. Strout の Mind Uploading Home Page（ibiblio 版）。当時の問いと、現在の読み替えは次の通り。

古典的論点当時の問い現在の読み替え
物理主義心は物理的な脳過程から生じるか作業仮定としては必要。ただし復元対象・十分条件は決まらない
ミクロトーム / 破壊的スキャン薄切り画像から脳を再構築できるか構造足場は強まるが、固定・保存・染色・時間遅延・現在状態の喪失が残る
ナノ置換 / Moravec 型連続置換徐々に置き換えれば同一性は保てるか連続性は直感的に強いが、各段階で機能・状態・身体ループが本当に保たれたかは未検証
非破壊アップロードMRI 等で生きたまま読み出せるか解像度・逆問題・proxy 性・共有ドライバー・モデル負荷が上限になる
人格同一性と複製コピーは本人か。複数コピーは許すか技術的復元 / 心理的連続性 / 法的同一性 / 社会的同意は別問題
人工現実 / 人工身体アップロード後の環境・身体はどうあるべきか身体・環境は周辺ではなく、内受容・報酬・睡眠・恒常性・社会関係を通じ状態を変える
社会影響人口・資源・権力・犯罪・権利をどう扱うか実現前から技術条件と制度条件を混ぜずに設計する必要

1.2 全脳エミュレーション（WBE）の現代的位置づけ

WBE は「抽象的哲学」から「測定と実装の問題」へ移った。一方で、配線図（コネクトーム）だけでは現在状態・可塑性・代謝・グリア・血管・免疫・記憶固定を閉じられないことも明確になった。

1.3 現在の到達点（比較的わかっていること）

  • 脳の情報処理は物理的基盤を持ち、測定可能な構造と活動に依存する。
  • 一部の神経信号から、行動・知覚・運動・言語に関わる状態を予測できる。
  • 公開データ・標準形式・再現可能な解析は、主張の検証力を上げる。
  • 単一の測定法だけでは、内部状態の一意性を閉じにくいことがわかっている。

1.4 主張の強さを5段階で分ける（混同してはいけない）

主張意味必要な追加証拠
相関二つの量が一緒に変わる交絡・共通原因の確認
予測ある信号から別の状態を当てられる別条件・別個体・別装置での汎化
識別候補状態を区別できる競合モデルが残らないことの検証
因果介入で結果が変わる摂動・反事実・保持された検証条件
再現別の人が同じ手順で確認できるデータ・コード・環境・評価の公開

1.5 クレームラダー L0–L5（進捗を読む物差し）

レベル何を示すかまだ言えないこと
L0公開データ・イベント・同期・QC・ベースラインが再現できる内部状態を識別できたとは言えない
L1複数手法を同じ条件で比較できる最良スコアが真の状態復元とは限らない
L2摂動や保持データで競合仮説を落とせる全脳・長期・身体込みの十分性はまだ別
L3閉ループ実装で特定機能を安定再現できる人格同一性や全体意識の主張には届かない
L4同一個体内で状態継続と再校正負荷を説明できるコピー問題・社会的同意・長期倫理は残る
L5技術・検証・運用・同意・停止条件が揃う哲学的同一性の立場まで自動解決はしない
  • 設計思想: 上位レベルの言葉を急ぐより、下位レベルを再現可能に厚くするほうが、現時点では研究速度を上げる。

1.6 主要エビデンス（文献は日付でなく「支える主張」で読む）

証拠クラス代表例強くなる主張まだ閉じないもの
全脳/大規模コネクトームDorkenwald+ (2024), MICrONS Consortium (2025)構造足場・局所回路・同一脳の構造機能対応現在のシナプス効率・放出状態・代謝・グリア・全状態の同時捕捉
コネクトーム制約モデルLappalainen+ (2024), Beiran & Litwin-Kumar (2025)構造が活動予測をどこまで改善するか構造だけで動力学が一意に決まったという主張
可観測性 / 識別可能性Villaverde (2019), Prinz+ (2004), Rasero+ (2024)測れる・区別できる・一意に決まるを分ける必要性観測量が多ければ内部状態が自動的に一意になるという主張
同一個体マルチモーダルVafaii+ (2024), Chen+ (2025)共通パターンとモダリティ固有パターンを同時に見られる複数モダリティを足せば一つの真の潜在状態に届くという主張
状態継続 / 時間ドリフトGallego+ (2020), Karpowicz+ (2025), Wilson+ (2025)潜在多様体・デコーダをドリフト下で安定化できる可能性安定性能が内部状態の同一性を保証するという主張
破壊的構造測定の保存問題Lu+ (2023)固定・保存・染色が超微細構造/細胞外空間に与える影響の監査必要性固定後構造が生体内の現在状態をそのまま残すという主張
データ標準と再現性BIDS, NWB, OpenNeuro第三者が同じデータを検証できる条件標準形式に置いただけで仮説分離・同一性が解けるという主張

2. どこができていないのか（未解決ギャップ集）

2.1 まだわかっていないこと（コア4問）

  1. どの粒度の構造と状態が、個人らしさ・記憶の再現に必要十分か。
  2. 生きた人間から、必要な状態変数をどこまで非破壊に測れるか。
  3. 同じ出力を生む複数の内部モデルを、どの実験で分離できるか。
  4. 長期にわたる安定性・学習・睡眠・身体性をどう検証するか。

2.2 三つの壁（どのルートも、ここを通らないと見かけの進歩で止まる）

壁よくある過読確認すべきこと
測定粒度の壁高密度・高解像・マルチモーダルなら必要状態をほぼ測れたと読む直接観測 / proxy / 推定 / 未測定を分け、各測定の時間窓と数量タイプを明示
識別性の壁予測精度が上がったから内部状態も一意に決まったと読む候補モデル空間・曖昧性クラス・保持データ・摂動・棄権規則を事前に固定
介入検証の壁相関やオフラインデコードが良いから因果的再実装に近いと読む摂動応答・閉ループ・状態遷移・日跨ぎ安定性・安全停止・別条件検証を要求

2.3 研究優先順位 P1–P8（＝未解決問題の優先リスト）

順位は流行や日付ではなく、未解決の大きさ・波及効果・検証可能性で決める。

優先未解決の中身（＝できていないこと）次に必要な実験
P1 識別可能性測定量が増えても、同じ観測を説明する内部状態が複数残る競合モデルを列挙し、状態遷移・持続励起・介入・保持データでどれが落ちるか事前登録
P2 維持状態コネクトームではシナプス効率・固有興奮性・代謝・ECM/PNN・睡眠・グリア・血管・免疫を固定できない各状態に、直接観測量・代理量・時間窓・摂動可能性・棄権境界を分けたカード化
P3 同一個体マルチモーダルEEG/fMRI/PET/MRSI/行動が同一対象から取れても共通因子と固有因子が混ざる同一セッションで共通因子・分岐因子・装置固有誤差・状態ラベルのずれを分離
P4 コネクトーム制約モデルの残差構造は足場だが、動的パラメータ・現在のシナプス状態を一意に決めない構造に活動記録・摂動・外部タスクを追加し、残る候補集合を明示
P5 状態継続ブリッジ同じ脳・被験者・デコーダでも、日跨ぎ・固定後の状態同一性は別問題運ばれる対象・許容誤差・失敗規則・再調整負荷・救済ルートを明示
P6 デコード≠エミュレーション言語・運動を高精度予測できても、内部状態を生成的に再実装したことにならない予測スコア・神経寄与・言語事前分布・閉ループ性能・長期安定性を別々に評価
P7 公開データで L0→L2 を厚く大きな主張の前提となる低レベル再現性がまだ薄いBIDS/NWB・イベントログ・同期・QC・保持データ・ベースライン・ショートカット対照・棄権規則を一体公開
P8 身体・環境・内受容ループ脳単体の再現では感覚・運動・報酬・睡眠・恒常性の閉ループを保証できないどの身体ループを保存/置換し、どの遅い内部環境を合わせるか実験ごとに開示

2.4 コネクトームに「黙って含めてはいけない」維持状態（P2 の中身）

配線図だけで固定できない遅い状態のファミリー。どれが個別機能に必要十分かは未解決。

固有興奮性 / AIS / イオンチャネル シナプス効率 / 放出確率 / 短期・長期可塑性 ECM / PNN / 局所プロテオスタシス 神経調節（DA/NA/ACh/5-HT/神経ペプチド） 転写 / クロマチン / RNA編集 / リン酸化 代謝 / ミトコンドリア / ATP / イオン環境 / 熱状態 ミエリン / 希突起膠細胞（伝導タイミング） グリア基質 / アストロサイト 血管 / BBB / 免疫 / クリアランス 睡眠 / リプレイ / 概日 / 発火率設定点 / 日跨ぎドリフト
  • 共通の過読警告: proxy が多いこと ≠ 対象状態が一意に復元できること。 一つの代謝指標や血流補正で「支持状態全体を測れた」と読まない。

2.5 身体・環境・倫理のギャップ（P8 と L4/L5）

  • 脳だけを切り出した実装で、人物性・意識の継続を主張できるかは閉じていない。
  • 技術的復元 / 心理的連続性 / 法的同一性 / 社会的同意は別の成功指標として分離が必要。
  • 未整理の制度条件: 同意・コピー数・分岐・更新・停止権・監査権限・悪用防止。

2.6 必要条件のうち「まだ閉じていない穴」

条件まだ閉じていない穴
状態空間の閉鎖どの維持状態が人格・記憶・技能に必要十分か
コネクトームの役割分離現在のシナプス効率・放出確率・可塑性履歴・代謝状態は別途必要
ヒト可観測性の上限PET/MRSI/dMRI/EEG/fMRI を組み合わせても一つの潜在状態へ自動合成できない
時間的妥当性「同じ被験者/同じ脳」というラベルだけでは状態継続を保証しない
身体・環境境界低遅延入出力だけでは遅い内部環境・身体性を閉じられない

4. 明日から最速で進めるなら（実行手順）

  1. 対象機能を一つ選ぶ記憶・運動・言語・覚醒など、まず狭く。
  2. 競合する内部状態説明を3つ以上書く同じ出力を別機構で説明する候補を先に出す。
  3. 観測量ではなく分離実験を選ぶどの測定/摂動が競合候補を最も落とすか。
  4. 棄権条件を公開する候補集合が重なるなら「成功」でなく「未識別」として止める。
  5. 公開データの小さな再現ループからL0 再解析 → L1 同条件ベンチ → L2 候補仮説分離。

公開データルートの最短順: Cue-locked EEG（イベント/分割を固める）→ 睡眠・長時間 EEG（状態ラベル/時間評価）→ 大規模臨床 EEG（ショートカットを壊す）→ 同一セッション・マルチモーダル（proxy 分解）→ 保持データ・摂動（L2 候補分離）。
